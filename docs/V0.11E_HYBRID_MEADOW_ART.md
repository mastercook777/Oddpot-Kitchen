# 《怪味食堂》香草小径 Hybrid Canvas 美术 v0.11-E · 试验规格

**日期：2026-10-14。用户在观看纯像素草地地图后改变方向：**“角色、NPC、敌人保留像素小人统一规格；场景不要完全像素化。用餐厅那套 Canvas 绘制方法画更精细的草地地图，避免旧场景杂乱和粗糙。”此规格覆盖先前 v0.11-D 的“全部场景像素化”**美术决定**，不推翻其已验证的路径/玩法。

**代码只在独立分支** `feat/herb-path-pixel-art-slice`（Draft PR #44），不得自行合入 `main`。

## 玩家能看到的变化
- **角色（保留像素）**：主角用 `pixelActor`；敌人用 `pixelEnemy`；旅人和可采食材用现有 16/20px 像素 Sprite；已有伤害/目标标识继续具备清晰识别度。
- **场景（改为画风精细、安静的 Canvas）**：草地使用柔和灰绿连续铺底，不再看到密密麻麻的 16px 砖格；少量大块柔光和阴影建立地表层次，禁止每块随机噪点。土路用连通安全路径的弧形接头/自然边界，并保留可辨识分岔。树木以精细树冠、木纹、高光、基底投影构成物体，而非旧版几何圆形的随意堆叠；岩石用有明暗关系的切面形；花草点缀稀疏而位置受游戏真实状态约束。
- **三层景深**：地表及小景先绘制；树石按现有规则在角色前/后适度遮挡，交互对象优先被看清；不增加误导玩家的假资源点。
- **一致性**：采取“场景柔和完整、角色及可拾取物轮廓硬朗”的二维混合视觉，不把像素角色偷偷改为 Canvas 角色，也不把场景切回纯像素。
- **性能**：颜色/路径/装饰布局继续读取已有的 `herbPixelGroundPlan`（同一真实 BFS 安全路及限量装饰），并为静态地表预渲染缓存；镜头移动时仅缩放/平移，不重复生成纹理。背景绘制保持在 12×16 世界尺寸范围。

## 代码交付
- 新建 `src/field_hybrid_meadow_v011e.js`：专门的 Canvas 连续地貌绘制；以 meadow 为唯一开关，留存原版像素场景供预览切换和回滚。
- 修改 `src/scenes_v04.js`：仅 `worldVersion==='0.11-B1'`、`biome.zoneId==='herb_path'` 时切换新草地和树石；像素食材、NPC、敌人、厨师保持旧通道。其他七生态、legacy 9×11 不变。
- `art-preview.html` 扩展为 Hybrid / Pixel / Legacy 三向真实引擎截图对照；`scripts/capture-herb-preview.mjs` 通过 Chrome 截取 430×932 移动视口。
- `scripts/build-standalone.py` 和 `standalone.html` 的模块顺序同步，仍可离线试玩。
- 新增 `tests/v011e_hybrid_meadow_art.test.js`：不同地图种子、安全路径、环境元素 Canvas 实际调用、三态切换、缓存和非草地隔离；保留旧版 338 项回归。

## 坚决不修改
探索敌人数量、AI、怪物种类、物理碰撞、采集数量、商人/奇遇判定、菜单/料理/餐馆、存档内容与完整三段探索。这轮只有**美术绘制**，不代表 v0.11-B2/C 已完成。

## 定义完成
真实游戏 `drawField` 画面通过自动截图验证，完全相同的真实场景在三种渲染方式下可对比；代码 + 离线包 + 测试都通过；PR 保持 Draft 等用户验收，iPhone 触控/帧率仍需真机确认。

## 已实现（2026-10-14，独立 Draft PR #44）

- 在真实 `src/scenes_v04.js` 中，以 `isHybridMeadow(f)` 选择连续 Canvas 草地；可切换纯像素预览回滚，`herb_path` 之外不触发。
- 已实装淡绿色渐变草地、低密度环境光斑、真实 BFS 铺路（缩窄土路、低对比色与曲线小偏移）、稀疏草簇、立体分层树冠/树干/岩石切面、随真实 hazardPhase 提示的危险裂隙。
- 厨师/敌人/旅人/食材保留已实装 `chef`、`pixelEnemy`、`drawHerbPixelNode` 的像素精灵；现有三段路线、采集、地图阻挡和奖励逻辑未改变。
- 性能：一张 12×16×64px 的离屏静态地表，按 `f` 对象 WeakMap 缓存；同一画面每帧复用一张贴图，非每帧遍历 192 个小图块；地貌物体单独按纵向层次绘制。
- 验证：**343/343 自动测试通过，0 失败**；移动端 Chrome `430×932` 真正执行 `drawField` 的 4 幅截图成功；`standalone.html` 的源代码与 `src/` 同步；真机 iPhone 操作/帧率待玩家本人验收。
- 正式版 `main` 未修改，PR 仍保持 Draft。
