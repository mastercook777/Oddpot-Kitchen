# v0.16-X · Visual Technology Lab
2026-11-24 · 用户认可独立技术实验，尤其希望验证 Canvas HD 的上限。A2.1 实机反馈为退步（直接裁 AI 像素素材、比例与纹理割裂），停止推广。Art Bible 的 2D 决策暂为候选，不再排除 3D。
## 范围
独立 visual-lab.html，与正式游戏同仓同 Pages，不读写游戏存档、不接经营引擎、不改变正式首页。共同实验布局：10×10 地面，两张桌、四凳、WOK/POT、柜台、储物架、窗、门、主角；实验内点击可走动，昼夜切换、炉火动态。此布局为比较夹具，不声称已接正式 DINER_FLOOR。
X1 Canvas HD：原创纯代码路径、渐变、材质、阴影、分层建筑、固定种子细节；缓存静态画面/物件可后续优化。无 AI 图片或外部贴图。X2 Three.js：共享布局，正交相机、程序模型、灯光阴影、动态火光。X3 同一 X2 模型低分辨率最近邻输出；不是完整像素 shader。X1 优先，X2/3 作为可操作对照，不以技术名代替画面品质。Three.js 固定版本 CDN 延迟加载，网络失败显示可返回 X1 的提示；X1 不依赖外部库。
## 验收
手机 320/375/390 宽、桌面：切换三种模式，同布局、昼夜、点地面移动，返回模式不丢实验位置；无存档、无正式经营副作用。检查画面真实可见、没有遮挡控件；记录实际 FPS（仅当前设备测量）、WebGL 失败和 CDN 依赖，不虚报测试。对比权重：画质30、一致性20、沉浸15、生产效率15、移动性能10、迁移成本10。禁止从概念图推断成品；最终取舍由玩家实机体验。首版为实验，不等于美术上限，下一轮优先按 X1 反馈深化。
