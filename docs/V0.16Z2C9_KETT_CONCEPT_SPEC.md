# Z2c9 · Kett 概念图低成本3D重构
2026-11-26；基线 Z2c8 PR #134 / 32f3beb，合并前17/17 CI成功，但玩家明确否决Z2c7/8造型：只是头变胖，缺少风格。玩家随后认可生成的Kett旅厨概念设定图（本项目对话，图中正/侧/背/3/4、红领巾、旋卷帽、翘发、冒险夹克、露齿笑、皮靴、斜包/铜徽/香料瓶），并明确不追求高精度3D、不换现有技术手段，先接近概念图。Kett仅内部代号。此记录固定造型参考，原图暂未存入仓库。
## 范围与方法
新独立造型模块，不沿用旧球脸+软帽+围裙的几何代码；只复用经过验证的动作函数与肩/肘/腕锚点，连续程序网格（弯曲渐缩扫掠、非球面下颌、衣物片曲面/剖面、帽冠偏心变形）配合简化手绘色块。剪影优先：右侧大片尖翘发束、偏左高卷帽、宽胸短夹克、红三角巾和背后飘带、短腿宽靴、露齿偏笑及粗眉；围裙下摆不对称，黄铜勋章、斜挎包、瓶作为次级信息。保留脚底、共享rig锚点、旧模型、两等级厨具。原理可在低端设备运行；无Blender/GLB/第三方素材，不承诺概念渲染精度。
只替换3D整备页；工坊增加Z2c9，默认新模型，可切换旧三版、四角度、近景/游戏小尺寸和静态/Idle。必要时调整整备相机画幅避免帽/头发裁切；不动布局、存档、玩法、经济、战斗/营业/其他角色。暂不设计新动画，保留Z2c8动作。
## 验收
真实Three实例化、八厨具等级248样本有限矩阵/烤叉握点，工坊WebGL切换、三宽度烟测。新增特征标记及几何边界检查，防止回到仅头宽变化。人工比较概念：帽与翘发剪影、笑容/眉、夹克与红巾、短靴和斜包；不以测试通过代替实景好看。待玩家反馈后决定模型是否迁移至战斗/营业。版本Z.2c9，保留旧档。若CI或发布未核实如实报告。
