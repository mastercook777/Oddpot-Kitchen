# v0.13-B · 全店厨具升级与智能补位（2026-10-15）

状态：用户 v0.13-A 实测后明确要求修正，设计稿先提交，再实施验证。

## 概念解耦
- 厨位：左WOK、右POT、中CENTER是历史物理工位ID，不等于锅具类别。三个物理厨位互有独立真实队列，只有人手才出餐。
- 厨具：WOK炒锅/POT炖锅是两类设备及两棵全店技术树。**每种厨具只需升级一次**。所有装有该类型厨具的真实厨位同享等级；改装卸下后技术仍在，探索武器仍按类型拥有等级。旧存档从已升的槽位和旧历史标志取最高等级初始化，不重复收费。
- 人员：阿火与小炭都是厨房劳动资源，升级套餐免费附带后不绑定新炉。两人可任意选左/右/中作为**优先岗位**；把A指派到B的岗位时直接两人换岗，而不是「岗位冲突」。工资、经验、员工餐继续独立。
- 动态补位：以优先岗位为常态，空闲而另一炉有真正对应订单且缺人时，厨师可前往支援。制作途中通常不离岗，跨炉移动需要实际模拟时间，视觉连续而非瞬移；只能在到达后算生产力。其他员工同站时禁止双帮厨重复叠加；主厨走位可临时并肩加工。岗位调整稳定防抖，不能每秒随机跳站。
- 不能凭空制造顾客、订单、食材和金币；原真实顾客耐心/星章/第四桌不改；一单只能扣一次材料、记一次收入，帮厨必须实际完成单才拿XP。
- 老schema4与营业快照：营业中旧班次继续按老字段逻辑，新班次才使用新的自动调度；历史设备等级不降级，场上已在制作订单不受改装影响。
- UI：升级页由“左/右/中灶台升级”改为“炒锅/炖锅全店共享升级”，备餐依然管理各厨位装哪种锅。员工页直说“优先厨位”，有人时按选择互换位置。
- 测试：两种同款锅共享等级、存档迁移、互换、空闲自动补位含移动时间、两个同类工位真实并行、人手下岗后炉不得幽灵开工、标准/低库存真实经营回归、Chrome手机320/375/390、离线完整游戏。
- 第二星、烤架、烤叉、水吧/饮品、甜品仍后置，本版只修经营调度基本盘。
