# v0.13-G · 真实经营引擎经济数值审计（非玩法改动）

2026-10-15 · 基线 main v0.13.0-alpha.6

## 目标与可信范围

针对玩家“体感不一定准确”的担忧，**直接执行现行 `src/engine.js` 的真实市场、购买、顾客计划、生产/上菜、收入、工资、宣传、两阶段二星评鉴**，采用相同随机种子的成对对照，避免用独立伪经营公式代替游戏代码。

**严格区分**：结算 `report.profit` 是营业会计利润（按实际材料耗用成本）；`s.coins` 的现金增减则包含真实采购付款、销售、工资和营销，采购导致现金减少但未耗用食材会保留在库存资产中。长期模拟中必须同时展示利润、现金、库存、缺料、弃排和负债。

## 模拟条件与变量

1. 独立单夜对照：相同种子 80 次（或更多），所有常用食材事先充足，便于隔离 2/3 厨位、混合/蔬食菜单、自然客流/24 金币田园宣传对真实上菜和利润的影响。第二星阶段 1/2 按引擎原判分条件申请并日结，不能“算出”人工假分数。
2. **连续21日供需现金流对照**：从已有双星/四桌/员工的中期存档情境开始，提供明确的同一初始本金和起始库存，统一稳定菜单、厨位/员工、主厨走位基准；每天只通过 `ensureDailyMarket` 中实际的当日四款上架和 `purchase` 真实扣金币，按库存目标自动采购，再通过 `createService/tick/closeService/advanceDay` 跑连续真实营业。**不能每日重置金币、仓库或补足无限材料**。固定最大采购目标与当日资金限额，无人工强行填满仓库。
3. 对照新版全部商品初始 6–10 份与**仅用于对照**的旧版上架额度（原平价 6–9、探索普通食材 2–4）。对照实现只在经济实验脚本中修改当日市场容量，用同 seed / 同四款上架 / 同价格 / 同客群需求；**不修改正式源代码、游戏存档 schema 或 UI**。
4. 关注四桌双炉/三炉、混合/蔬食菜单与付费田园宣传。允许可选“每天安全探索固定带回 8 份指定常规食材”的**外生供给敏感性情景**；不能称它是真实探索/打怪模拟、更不能把探索的 HP、时间、Boss 回报或背包丢弃成本估为零后宣称探索净赚。显示其作为免费材料上限假设的经济影响，正统探索需另开仿真工具。
5. 同种子成对输出均值、P10/P90、差异、缺料天数、实际成交、现金增减、平均店面利润、采购花费、库存结余、工资债务和二星达标率。明确数据是**固定站位主厨（右炉）**与静态菜单的模型，非玩家手动摇杆技能表现；不采纳模型作为体验达成保证。

## 风险及验收

- 市场卖光不可当日补货，未上架项不可买，Boss/稀有材料仍不可买。采购次数/单价读取唯一市场状态，现行 `schema5`；
- 付费宣传必须真实扣 24 金币、增加对应 2 位可能失败的顾客，不能直接加 2 单成功收入。
- 旧额外供应量只作为 **what-if** 成对基准，测试脚本不可导出到玩家运行时。
- 结果作为路线图的经济决策输入，不直接改变采购下限、评星门槛或营销价；如数据证明需要调优，先设计后实施、再自动回归和 iPhone 验收。

## 本轮实测完成（2026-10-15）

- [完整经济报告](V0.13G_ECONOMY_RESULTS.md)；[可复现实验工作流](https://github.com/mastercook777/Oddpot-Kitchen/actions/runs/38751591693)，32个seed ×21日 ×12种策略（8,064实际连续营业夜），另有80 seed×10场景单夜隔离。
- 新供货6–10使混合三炉日均真实上菜5.06→5.79，蔬食三炉4.51→5.82，期末现金分别提高约142/174金币，但市场唯一供给且固定菜单时平均每21晚约20.8晚发生缺料；不能称现实游玩必然如此。
- 真实田园品鉴新增两位来客并扣24金币：库存充足时真实成交增长仅约0.60/0.66；利润平均分别减21.97/18.60；21日固定营销策略平均终现金减约485金币。
- 采购目标12→20份只把日销量5.79→6.14（混合）/5.82→6.25（蔬食），缺料发生仍约20.5天；应把菜单动态调配与探索真实回报列为下轮验证。
- 外部额外8份/日能够增加上菜与现金，但是假定外生补给，**没有模拟探索路线、HP、战斗、移动时间、背包与真实产出**，不能用来宣称探索的净ROI。
- 评星在充足供料且固定主厨情况下：首夜双炉85%、三炉93%；次夜双炉99%、三炉100%，提示第二夜相对宽松，仍需要更广泛的真实游玩/菜单策略样本验证。
- 全部数据是数值/规则实验，不修改正式版本的采购、工资、宣传或评星参数；后续调参先完成独立设计与回归。
