## 三种方向与选择
A 酒馆木牌/黄铜：适合UI底座、按钮、菜单牌；若全部同色同框容易复归工具栏。
B 厨房器物/火候：适合技能、餐具、精力、便当；过度写实会在17px失读。
C 奇幻餐厅/手作徽记：主体为有体积的插画化物件，局部木、铜、陶、皮革、火焰、青玉，少量非对称与奇幻细节。选择C作总体，借A作按钮材质，B作动作语义。不是三套皮肤。此为设计决定，玩家实机可修订。
## 资产规则
- 全部31个既有key保留，采用24单位手工分层矢量，不依赖Emoji/字体或网络；先读轮廓再读材质，主面/暗面/高光，深棕墨轮廓，局部内线，明确光源左上。非同色纯线；不靠给旧线框加外框冒充升级。按物件使用陶白、铜金、茶棕、松石、莓红、青玉；避免统一金色和过饱和。技能以厨具主体+动作剪影/能量色绘制：炒锅旋风青玉、沸汤蓝绿/金、烤叉橙红火焰、蒸笼淡青雾。暂停/继续保持惯用含义，做成铜质嵌件，不为世界观牺牲可理解性。
