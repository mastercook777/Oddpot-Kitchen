## 三种方向与选择
A 酒馆木牌/黄铜：适合UI底座、按钮、菜单牌；若全部同色同框容易复归工具栏。
B 厨房器物/火候：适合技能、餐具、精力、便当；过度写实会在17px失读。
C 奇幻餐厅/手作徽记：主体为有体积的插画化物件，局部木、铜、陶、皮革、火焰、青玉，少量非对称与奇幻细节。选择C作总体，借A作按钮材质，B作动作语义。不是三套皮肤。此为设计决定，玩家实机可修订。
