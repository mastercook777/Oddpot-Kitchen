# 《怪味食堂》探索美术 Vertical Slice v0.1：香草小径

**状态：可玩隔离试验分支；玩家真机验收前不得合并**  
**分支：** `feat/herb-path-pixel-art-slice`（基于 main v0.11.0-alpha.3）  
**范围：** 仅新增的 `worldVersion='0.11-B1'` 且 `biome.zoneId='herb_path'` 探索场景。原有餐馆 / 烹饪 / 经济 / 三段探索 / Boss / 其他七种生态 / 旧存档不改。  
**目的：** 用真实可运行的样板验证“程序像素角色能否自然带动整个世界的统一美术风格”，而不是先撰写一大套无法验证的风格指南。

## 1. 玩家痛点与方案

B1 12×16、跟随镜头扩大了空间，但程序绘制的椭圆、曲线树冠、漫反射色块和像素主角不属于同一视觉语言。玩家已要求先从角色的**真正像素格**出发，渐进改进探索美术，暂不重做经营。优先采用 **RotMG 式小尺寸清晰轮廓**，保留《怪味食堂》的温暖绿金配色，不改变现有动作游戏玩法为纯弹幕游戏。

这次直接落地**16×16 虚拟 Tile**：可缓存的 offscreen Canvas 资产在 native 16px 纹理上逐像素绘制，游戏画面通过 `drawImage` 以最近邻放大，不使用 Canvas `ellipse/arc` 等抗锯齿几何来伪装像素画。以当前 `src/pixels_v041.js` 的 18×24 左右厨师与怪物为人物尺寸基准。

### 基础视觉语法
- **像素比例：** 地板/路面 16×16；树 24×30，岩石 16×16；食材 16×16；旅人 20×28。初版作为可调整规范，不强制外推至餐馆。
- **轮廓：** 单色深绿灰近黑描边；主体 2–3 阶亮度；光照来自左上方。线条和色块按像素整数而非任意小数绘制。
- **色板：** 深轮廓 #26352e、地草 #527546、高光草 #a5b96b、土路 #96734d/ #c49a67、树皮 #75523d、石灰 #697871、交互亮金 #f7dfa1。细节颜色集中在 `HERB_PIXEL_PALETTE`。
- **可走路地块：** 草地四种受种子影响的像素变化；真实 BFS 主路使用相邻 `N/E/S/W` 连通的土路图块，避免画出通往实体障碍的虚假大道；小花和草丛是无碰撞微装饰，绝不改变判定。
- **互动可读性：** 大体块的蒜、菜、洋葱、土豆、蘑菇、辣椒、肉，目标四角金标记；旅人以角色比例呈现并用亮标识区分；危险地块和激活提示使用方形像素，不再画圆圈裂隙。
- **物理一致性：** 既有 `obstacles/hazards/nodes` 为坐标唯一来源，所有碰撞、资源、商人、敌人路径仍由引擎而非美术决定。

## 2. 实现边界与代码入口

- `src/field_pixel_herb_v011c.js`：统一色板与尺寸、缓存 Canvas sprite、草地 tile、16 种土路邻接变化、树石和资源/NPC/陷阱可辨精灵；`isHerbPixelSlice` 是**只读**区域开关。
- `src/scenes_v04.js`：只在香草小径地形、障碍、采集点、旅人、危险渲染走新路径；现有主角、敌人逻辑与绘制、交互、碰撞、摄像机及普通 HUD 不变。
- `scripts/build-standalone.py`、`standalone.html`：支持直接打开的自包含试玩版本，源模块排在 `scenes_v04.js` 前。浏览器模块版和单文件版需同时测试。
- **不添加正式外部图包，也不使用任何其他游戏的受版权保护素材。** 完全是项目自制的程序像素资产。

## 3. 验收标准

1. 「香草小径」手机纵屏的同一画面中，主厨、敌人、场景与采集物属于相近的低像素分辨率，前景主体不被花草干扰；附近树林与远处不呈现光滑的矢量几何。
2. 三段正常游玩、一次性旅人、采集、怪物、伤害、撤离、背包库存结算全不变。图块只看真实地图；不会多出隐形墙或将障碍画成可通行物。
3. 非 `herb_path`（其余七生态）及旧 9×11 存档渲染完全走旧逻辑；新模块不污染存档、物品、随机种子，也不每帧创建无上限的纹理资源。
4. 测试涵盖所有资产尺寸、缓存渲染调用、区域开关、实际 BFS 土路、地图绘制与旧地区隔离；Core CI/Playable CI 通过和离线构建可解释；**自动回归 ≠ 手机观感验收**。

## 4. 如何试玩（不能打开主站检查这个分支）

主站 https://mastercook777.github.io/Oddpot-Kitchen/ 仍然是 main，**不会显示样板**。在 GitHub 仓库切到 `feat/herb-path-pixel-art-slice`：

```bash
git clone https://github.com/mastercook777/Oddpot-Kitchen.git
cd Oddpot-Kitchen
git switch feat/herb-path-pixel-art-slice
npm install
npm run dev
```

打开终端中的 Vite 本地服务地址，在「准备出门探索」选择森林安全路线（第一段 `herb_path`）就能体验。也可以直接从分支下载单文件 `standalone.html`，在支持本地 HTML/JavaScript 的桌面浏览器中打开；移动端浏览器对本地 HTML 的限制因系统而异。如果使用 GitHub Codespaces，选择此分支创建 Codespace，在端口转发中打开 5173 的 HTTPS 预览，可用手机浏览器试玩。这里尚未为分支部署独立的官方 GitHub Pages 地址。
