# 《怪味食堂》v0.8 · 厨具 × 探索武器双用途系统（设计规格 v0.1）

日期：2026-10-12 · 状态：设计候选，未实装，参数待可玩验证。
上位约束：docs/V0.8_THREE_STAGE_EXPLORATION_AND_STOCK_SPEC_v0.1.md；以及既有 v0.6.3-B 工艺闭环、v0.5A 双厨位升级机制、v0.7.5 走位经营规则。不能把本游戏变成战斗主导的 Roguelite；探索目的是为研发菜谱与营业获取食材。本文是本期 v0.8 探索重构的附属工作流。

## 1. 核心机制：一口厨具、两种玩法

玩家在餐馆有两个实体厨位（可配置 WOK/POT；现有等级最高 Lv2，买升级成本左位 60 金币/右位 75 金币，Lv2 每单基础制作时间 -2s）。
出发时选择一个**当前配置的厨位**作为携带厨具（左或右）：其 type 决定探索攻击模式，现有 level 决定野外武器的适度强化。**同一笔已经支付的厨位升级，经营层面缩短实际工时，探索层面增强对应出战武器**；不引入独立武器等级、战斗经验、材料货币或另收费。

重要现状：当前 kitchen.slots[index].level 属于**物理厨位**，不是 type 的独立永久等级，重配锅不会清等级。v0.8 第一阶段以从现有 slot 快照解析 weapon(type, level, sourceSlotIndex) 的适配方式实现，避免误把 WOK 设成永久 Lv2 而 POT 还是 Lv1。未来如将厨具真正实体化为 cookwareId + type + level + assignedPositionId，必须另写非破坏性旧存档迁移，不得当前版本偷偷改变升级归属。

### 装备选择和游戏日流程

出发准备页在地区/目标食材/便当之外，追加紧凑的「出战厨具」选项，列出当前两个厨位的实际类型与 Lv。首次默认选择左厨位（仅旧存档迁移的默认，不主动改厨房配置）；若两位都是 WOK/POT 则只能选同一风格但可选不同等级；不得凭空选择未配置的 POT/WOK。选择出发后 field.weaponSnapshot = {slotIndex, type, level, attackId, skillId}，并在三个连续区段保持不变。回店后厨房仍可在 PREP 阶段改位；任何 refit 或永久升级不得反向修改一场进行中的探索快照。第 N 天出发读取上一次厨房配置，后续预备/营业时可改厨房分工。

UI 只显示一条「WOK Lv2 · 近战/格挡」或「POT Lv1 · 远程/投弹」，可点击查看简述；保留一根移动摇杆、自动普攻、一个主动技能。战斗选型成为做菜准备的附加决策，不能把菜单选择/研究/双工位操作移到探索前。没有厨具选择时允许安全默认且明确反馈，防止软锁。

## 2. WOK（剑盾近战）：锅铲/锅体横扫 + 锅盖格挡

视觉：一手挥炒锅或大锅铲做「剑」，另一手持锅盖当盾；近战普攻自动锁最近合法敌人，跟随方向角色转向，无独立手动瞄准。短弧形前方横扫，每次最多命中 2 个可见目标；推荐初值：攻击范围 1.25 个世界格、伤害 1、间隔 0.70 秒，弧度 90°，必须前方有可打中的敌人才挥击；由统一敌人受伤逻辑结算。

唯一主动技能「锅盖反击」（沿用旧锅铲击退的资源和主要功能）：按下立即横扫击退半径 1.8 格内敌人，并在 0.45 秒的可见窗口阻挡来自面前方向的一次普通敌人攻击或飞行弹；冷却推荐沿用 6.5 秒。不能连续挡住 Boss 多段攻击，也不能通过暂停或长按保持永久无敌；Boss 仍有侧面和地面危险需要走位规避。

Lv2 推荐效果：横扫角度 90°→105°、格挡窗口 0.45→0.55 秒，不直接翻倍基础伤害。Lv1 要能完成所有设计的 Mini Boss，Lv2 只使节奏更稳。现有便当环境伤害减免仍是单独结算来源，不与盾牌无限叠加。格挡反馈应明确显示一次成功防护以及被挡攻击的实体来源。

## 3. POT（远程投弹）：洋葱炸弹 + 汤锅冲击

视觉：汤锅魔法弹射「洋葱炸弹」，利用现有 2D 场景绘制简短抛物线高度假象（视觉层），实际命中逻辑依据确定性世界平面落点；自动攻击最近的视线有效敌人（上限约 3.5 世界格）。默认每 1.2 秒发射一颗，爆炸半径约 0.65 格，对范围内每个合法敌人各造成 1 点伤害，不能对同一目标一发多重判伤。攻击有短暂弹道时间；追踪与命中不能直接读取绘画帧的视觉坐标。敌人贴身时较脆弱，没有 WOK 的格挡。

唯一主动技能「高压汤锅」：向当前最近有效敌人的位置发射强化洋葱弹，落地对小范围目标造成较高但有限的爆炸伤害（初值 2），附带约 0.8 秒减速，冷却初值 6.5 秒；如果范围内无敌人，应仍有明确施放指示或者用灰态阻止误触（规则需一致）。减速仅影响可减速目标，Boss 可部分抗性而非免疫整个技能；不替换已有自动攻击和移动按钮。

Lv2 推荐效果：基础爆炸半径 0.65→0.75，普通投弹间隔 1.20→1.10 秒。避免叠加多个 AoE、穿墙无条件命中或连续刷新技能。洋葱炸弹属于厨具魔法的视觉弹药，**普攻/技能均不消耗真正的洋葱原料**；不能因为 v0.8 把 onion 定义为 FIELD_ONLY 就令 POT 无法开火，也不能用空库存直接奖励更多资源。

## 4. 同一 Mini Boss 的双流派可行性

**古树孢巢·孢冠菇王**：扩散孢子环+短冲撞；WOK 可等待冲锋结束后的安全窗口近身反击，POT 可保持距离投弹，但会被持续孢子云限制走位。Boss 必须有开放给 WOK 的近战安全窗，且不可一直原地站桩让 POT 无伤击破。
**赤焰断坡·熔壳椒王**：直线喷火+蓄力冲刺；WOK 通过横向闪避或有时机的锅盖防护接近，POT 利用距离优势攻击但要规避冲刺路线和地面热泉。Lv1 两类厨具无需装备专属升级均可获胜。
区段风险取舍与背包/撤离仍为探索主要策略：不能为了保底打赢把 Boss 变成每日强制刷取、DPS 挂机或稀有掉落概率搏运气。

## 5. 与经营的双向连接

- Lv2 同时表现「该物理厨位每单基础时间 -2 秒」和「该厨位出战武器获得专属动作/数值小强化」；只有实际已购升级生效。
- 无新战斗素材掉落作为升级付费；升级使用既有金币和唯一事务账本，仍由 src/engine.js 结算。
- 顾客订单/餐馆生产效率、菜谱工艺/品质、员工效应保持目前唯一 source of truth。武器特效不得修改料理事件/顾客交易事件。
- 将来其他厨具定义 CookerWeaponProfile 配对：新锅具必须提供 cookingRole / stationCompatibility / fieldBasicAttack / fieldSkill / perLevelPerk / weakness / BossCounterplay；至少一个实际经营策略新选择，不可仅换武器皮肤。
- 推荐后续候选：OVEN 烤炉＝慢速远程火焰直线蓄能；GRILL 烤架＝中近距离持续灼烧。**v0.8 不实装第三种锅具**，只预留通用注册机制。

## 6. 技术接入（Codex 输入）

推荐新增独立模块 src/cookware_weapons_v08.js（纯配置/规则）：
- getFieldWeaponCandidates(kitchenState) → slotIndex/type/level/preview
- resolveWeaponSnapshot(kitchen,selectedSlotIndex) → immutable weapon state
- resolveWeaponBasicHit(fieldState,weapon,dt) → damage events
- resolveWeaponSkill(fieldState,weapon,action) → world hit/block/slow events
- applyFieldDamage(entityId,eventId,amount) → 统一敌人伤害与单次击败奖励入口
- createPlayerProjectile(snapshot,seed,origin,target) → deterministic shot object
- presentWeaponEffects(snapshot/events) → Canvas 专属表现，不发资源

当前 src/field_v04.js 的步进内固定“最近目标范围 <1.25 / 每 0.72s / 伤害 1”与 useFieldSkill 固定范围伤害 2 必须替换为依据 weaponSnapshot 分派，不再继续复制一套独立战斗循环。敌人 f.projectiles 与玩家新 playerProjectiles / projectiles.owner 需明确区分；碰撞、死亡与掉落统一走只一次的事件处理器。src/scenes_v04.js 的角色绘制根据实际快照变更持锅/锅盖/汤锅射击姿态；src/app.js 的探索准备与战斗技能文字读取所选武器而不是写死“锅铲”。

**旧存档与旧场景过渡：** 旧 ongoing field 没有 weaponSnapshot，加载时根据当前厨房首个可用 slot 推导一次，并持久化；若载入时已记录武器不得重抽或切换。当前 v0.7.8 的 0.4 存档 schema=4 保留；若需要 bump，必须实现迁移。不存在 invalid kitchen 的初始存档；错误值需安全回退基础 WOK。

**三段流程：** 选择武器仅在 PREPARE，三段不免费切换武器、补冷却或重置生命。切后台/分支选择暂停冷却和飞弹步进；加载恢复飞弹/敌人 HP/技能冷却与种子一致。

## 7. 游戏数值和体验测试（必须）

- 同一金币升级左/右实体厨位，在相同菜谱和工位条件下仍保持真实工时减免，同时已选对应 slot 的野外 weaponSnapshot 从 Lv1 升级 Lv2 的效果可复现。
- 重配 WOK/POT 后厨位等级保留；选择右/左真实 type 得到不同玩法；两个 slot 同类型时不变出未配置类型。
- 当前 run 锁定 type/level，出发后任何内部配置改变不追溯修改；跨三段 HP、弹药效果、cd 和武器一致。
- 默认武器旧存档可恢复，不使已经开始的老探索出现 double boss/重领奖/无技能按钮。
- WOK 横扫每次目标数量正确，技能格挡至多一次有效普通攻击，前方/方向和 Boss 范围规则清晰；不会无条件无敌。
- POT 普攻/技能无原料扣除，弹道与爆炸对单个敌人仅一次判伤；不可穿障/无限远攻击；爆炸碰撞和稀有食材拾取互不影响。
- 相同 seed+动作得到同一敌人死亡时序/掉落，同场不得重复触发 enemy_defeated；刷新在弹丸飞行期间不会多打一次。
- WOK Lv1、POT Lv1 在两个地区固定第三段 Boss 均有可完成路径；WOK 不会因 Boss 永久远距无法触及，POT 不能完全无伤站桩击杀。
- 1段安全退出、2段继续、3段 Boss、失败撤离等每条完整链路可进入 RESEARCH→真实新菜→餐馆营业，经济不双计。
- 手机 320×568、375×667、390×844 横竖安全区域、摇杆及技能按钮不误触，武器动画不会让场景掉帧；npm test + standalone 同步。
