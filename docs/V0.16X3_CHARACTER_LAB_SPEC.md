# v0.16-X.3 · Character Lab / Pixel Actor V3
2026-11-24 · 玩家认可 V2 证明代码绘制精度，但造型生硬像机器人；确认三个原创造型实验。冻结 Canvas HD V2 环境，保留普通 3D，Pixel 3D 已淘汰。
## 目标
A 紧凑冒险厨师（夜勤人式比例参考）；B 圆润 JRPG 厨师（缩小帽式轮廓参考）；C 温馨生活型厨师（杏林物语式亲和力参考）。仅借鉴造型原则，不复用他作资产。保留蓝衣、白帽、奶油围裙、红领巾、暖肤色。32×44 固定画布，原生整数网格，彩色描边、连续簇、非机械对称肩手腿。轮廓优先于细节。
## 交付
独立 character-lab.html：三个造型并列、原版与 V2 对照在原 visual-lab；可切换前/后/侧/左、待机/步行、倍率、暂停逐帧，提供进入真实 Canvas HD V2 走位查看的链接。原创代码像素矩阵，基于手工定义的全姿态帧序列（可共享帽/脸色簇，步态关键帧不以正弦驱动四肢）。前/后/侧各自姿态，左镜像。第一批 4 帧 idle、6 帧 walk，以关键姿态及重复/镜像过渡组成；尚不做烹饪/端菜/攻击等正式动作。环境、正式游戏、存档、经济不改。
## 验收
三个轮廓可辨、原始像素清晰、脚锚一致、动作具有重心转移、上下文比例自然；320/375/390 手机、播放/暂停/逐帧/方向/倍数、场景实际移动；无外部图片/字体/网络依赖，Node 矩阵验证及浏览器结果如实记录。最终角色选择由玩家确认，未获批不迁移全游戏。
