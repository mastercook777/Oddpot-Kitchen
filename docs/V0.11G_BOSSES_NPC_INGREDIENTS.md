# v0.11-G / alpha.5 · Mini Boss、商人比例与食材统一

**状态：已确认问题与方向，待实现；2026-10-14。**
**基线：** main alpha.4，Hybrid 八生态已正式推广。用户反馈质感明显升级，但 Boss 占位不匹配，商人太大/星标不合适，食材应跨模块统一。

## 玩家体验与范围

- 两名 Mini Boss 本体重新绘制为原生像素：菌王以大型分层菌盖、木质甲壳、孢心/根爪体现重量；熔心椒王以椒冠、熔岩铠甲、宽肩与炽亮眼神体现压迫。屏幕高度约主厨1.5–1.8倍、宽度约1.8–2.2倍，细节有结构，特效继续平滑Canvas。角色尺寸只改变美术，不虚增敌人碰撞/血量。
- 每名Boss新增三种轮换攻击，固定前摇/锁定目标/可躲避；保留10HP、单次1伤害、原盾/受伤保护、掉落与第三段风险路线门槛。不用更高参数冒充升级。
- 现有旅人/商人NPC按主厨相近的固定屏幕像素比例绘制，不再按世界格随地图放大。头顶用平滑感叹号，保持同一交互节点与触发距离。当前仍是旧旅人交易；本轮不虚称C阶段稀有商人已开发。
- 10种食材共用探索的程序像素图标来源：野外、背包、目标选择、仓库/采购、研发选料/锅内投料/熟度与复盘、便当/配方需求/缺料/灵感。完成料理与功能按钮另属图标类型，本轮不擅自重画。

## Boss 行为与测试数值（初版待体验平衡）

| Boss | 攻击 | 明确预警与实际执行 |
| --- | --- | --- |
| 菌王 | 孢子扇射 | 0.85s前摇，锁定方向，3枚慢弹，保留可绕开间隙 |
| 菌王 | 定点孢震 | 1.0s前摇，锁定玩家当时的位置；半径0.8圆预警后短暂命中区，移动可躲开 |
| 菌王 | 留缺口的孢环 | 1.05s前摇，环向慢弹，沿锁定方向保留逃生缺口；不全屏封死 |

| 椒王 | 直线冲锋 | 0.95s前摇，锁定方向/路线，短距约2.4格；实际移动按障碍截停，线形预警与真实宽度一致 |
| 椒王 | 定点熔爆 | 1.0s前摇，锁定玩家旧位置，半径0.8；短命中区、不叠永久地形陷阱 |

每次出招后留约2.2s恢复；循序轮换，无随机重抽。旧存档正处于旧前摇时先完成其原扇射，下一次再进入新轮换。Boss死亡取消尚未执行的冲锋与命中区。动态圈记录在field可选运行状态内，存档schema4不变；读档不重新抽招/发奖。远离4格察觉距离不主动启动攻击。

## 代码与资产契约

- 新 `field_bosses_v011g.js`：Boss行为/屏幕像素本体/平滑预警接口，`field_v04.js`复用唯一hurt/掉落逻辑。
- `field_pixel_herb_v011c.js` 导出可采食材sprite入口；新 `ingredient_icons_v011g.js` 为DOM图标生成一次PNG data URL缓存，Canvas与DOM来自同一程序像素资源；新增CSS只限定图标尺寸，不替换文本/交互命中层。
- 商人使用与主厨相近的固定像素标尺；平滑感叹号按同屏幕尺度锚定头顶。节点与碰撞不变，不加新浮窗。
- 正式版本、缓存查询、package/title/settings/standalone同步alpha.5。原E.1基准Site保留，不更动其历史样板。
