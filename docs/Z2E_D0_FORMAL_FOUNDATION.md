# Z2e-D0 · 正式 UI 2.0 公用基础
2026-11-27，玩家确认R3验收成立，但独立工坊UI网页感重，不得用于正式游戏。基线PR158 f82088f，20/20 CI。冻结CB工坊作为玩法验证基准，回归Z2e-D；遵守 GAME_UI_ARCHITECTURE_V2 第7–9节与 Design System 1.0。

## 本轮范围
- 正式 app.js 的野外/营业共用连续模拟摇杆；默认浮动不改既有54半径/9死区。固定模式左下真实场景内，常驻于可移动状态，触点需在固定基座附近才认领，拖动连续，第二指技能保留。设置页切换，设备本地偏好独立于正式游戏存档，异常存储降级默认。切换、失焦、窗口、事件、暂停、阶段和指针取消清空输入，保留已有抽屉焦点/滚动恢复；窗口背景不再接受交互。固定位置受场景尺寸约束。
- 餐厅Y2释放：源代码遍历material/geometry时不保证具备dispose；明确区分可释放资源与非资源，去重，单项异常不阻止renderer.dispose/forceContextLoss，记录异常。暂不大改其他渲染器或模型。
- 正式设置窗口复用原游戏图标与实体按钮，禁止复制CB工坊页面；完整共享视觉窗口在D1逐场景迁移。正式玩法/库存/经济/旧档/章节不改；不提前接入CB3。
## 验收
纯函数固定锚点/命中/偏好容错/连续向量，资源去重及异常后最终释放；真实正式页面固定/浮动设置、持久化、野外/营业双指、窗口关闭/暂停/失焦、三尺寸及2D/3D/离线回归。区分实跑、CI、部署与玩家验收。下一轮D1经营后链，D3整备探索，D2/D4+CB3，D5全日，Z3暂停。
