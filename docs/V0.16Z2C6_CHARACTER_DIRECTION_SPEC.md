# Z2c6 · Hearthcraft 旅厨角色风格验证
状态：研究结论及待验证实现方案；2026-11-26；基线 main Z.2c5 / PR #131。
## 1 问题与目标
玩家认可Z2c5人体连续性，仍认为generic、idle僵硬、缺乏风格。保留Z2c4整备布局，以主角为唯一验证切片；目标是即使遮住厨具也能凭轮廓、脸和动作识别的温暖奇幻旅厨。不是全游戏换皮。
## 2 参考与原创方向
- [Overcooked! 2](https://www.team17.com/games/overcooked-2)：圆润、职业读形、动物与人类共存、喜剧感；不照搬高帽、球状身体或制服。
- [Squad Busters 角色美术作者](https://www.chrispalamara.com/post/squad-busters-global-launch)：参考夸张头手足、独特剪影、表情与姿态的个性；不照搬具体角色、纹样、颜色、模型或战斗手游饱和度。
- 主参考后者的角色塑造，辅以前者的亲和；延续Z2a3 Hearthcraft 暖木黄铜、手作器物和已认可蓝绿/红巾/奶油帽。拟定原型名“炉火旅厨”，不是正式新增角色名字。
## 3 形体与姿态
头与帽组合形成偏斜软贝雷厨帽剪影，宽颊、饱满鼻、粗眉、有偏向的笑容，大片发束；加大头手足、收短躯干视觉比例，但不改原肩腕锚点或腿脚接地。围裙形成弧面、斜肩巾及黄铜徽，避免小件堆叠；衣料哑光、铜件柔和高光，使用现有程序化材质。正面3/4、既有实际画幅。控制武器遮脸及帽子裁剪。
Idle：先设计站姿再动，重心微偏、脚掌不滑、躯干/头反向补偿；不连续左右摇摆。呼吸、异步视线、短眨眼、偶发轻抬眉/颔首；围巾跟随，换装短亮相。共享武器rig仍接管双手且不覆盖头部表情；动作仅视觉。不同装备共用角色识别特征。
## 4 代码与风险
以src/three_z2c5_chef_portrait.js为基线，新增独立Z2c6候选（保留旧模型便于A/B），离散动作节奏纯函数可测试；接入src/three_z2c3_departure.js、index版本及缓存、相关测试。检查肩/肘/腕与武器双握点，脚底接地、面部裁剪、绘制开销。保留atlas/自适应频率/恢复/资源释放。未改战斗、营业、其他角色、数值、经济、存档、2D与离线。无新第三方素材、无引擎迁移。
## 5 验收及分期
1. 相同镜头与装备A/B截图、全身及面部；看轮廓而不是数零件；四装备Lv1/2不挡脸或脱手。
2. 连续10秒实景录像，看非同步眨眼、站姿/呼吸、换装和脚底稳定，避免机械晃动。320/375/390与真实iOS/Android帧率待验，保留Z2c5性能机制。
3. npm test、npm run build、3D烟测、全玩法回归、Pages版本分别记录；失败/未执行不得写通过。用户认可视觉后才设计营业/探索共用资产及顾客差异化；日报/成长/图鉴暂缓。
## 6 决策与限制
参考方向为本轮提案，不是玩家已确认最终美术定版。现有程序建模是可操作风格候选，不等于正式雕刻/拓扑/骨骼资产。容器git DNS无法解析github.com；通过连接器读取与写入仓库，若无法完成真实构建/截图/CI则不把候选作为已发布功能。记录具体未验收项。
