# 《怪味食堂》v0.4.4 · 探索/经营 HUD 减法

状态：2026-10-10 手机交互原型更新，仍待真实 iPhone Safari 玩家验收。

## 目标和原则

v0.4.3 的页面整体不再拥挤，但探索中的说明文字、技能按钮位置，以及经营中遮挡餐厅主体的多个状态标签仍不符合手机游戏 HUD 体验。

保留实时探索、浮动摇杆、自动攻击、料理构筑、两张地图与经营事件规则，不调整库存、营业时间、收入和挑战分数。当前 **没有引入第三套游戏系统**。

## A 探索 HUD

- 常驻：体力（3 颗心）、背包占用（点开详情）、已探索秒数。其他库存文字不在屏幕顶部轮播。
- 锅铲技能：放在场景右下角，独立圆形触控区，显示冷却秒数；左手触摸场景可随处唤起浮动摇杆。
- 支持双指：使用 `pointerdown` 触发技能，不依赖移动中浏览器是否派发第二指的合成 `click`。技能激活不会清理第一指的移动状态。
- 原本长期占用森林底部的操作说明取消；采集、受伤、线索以短暂小通知表示。
- 选路界面文案只保留缺口、目的地、路线差异和选择动作，不重复写长段教程。

## B 经营 HUD

- 常驻：一条简洁的第 N 波、营业时间、已上菜数量；仅在暂停时附加状态。
- 炒锅与炖锅可点区域不变，但可视标签收缩到工位下方，不用大色块遮挡锅和主厨。
- 餐桌本身由 Canvas 画，移除在桌面重复写菜名/气泡；桌位操作状态贴在靠近餐桌的位置。未占用桌位不强制挂空位大标签。
- 点击某桌后，当前订单和耐心显示在底部操作栏而不是压在顾客头上。
- 暂时出现的营业消息在约 1.9 秒后消失；波次间经营事件仍使用需要明确选择的决策面板。
- 餐厅画面继续使用 v0.4.2 缩小镜头和 v0.4.1 的像素小人，不再次调大人物。

## 验收

- 保留 47 项引擎回归测试。
- Chromium 模拟 390×844、375×667、320×568：可进入森林、使用技能、撤离、研发跳过、配菜单、进入营业、点击餐桌；无 JS 错误和整体滚动。
- 双指 CDP 验证：第一指摇杆持续位移中，第二指按住技能触发冷却，第二指释放后第一指仍保持激活。
- 餐厅点击暂停后， Canvas 在连续绘制间保持一致；非关键消息约两秒后自动隐藏。
- 真实 iPhone Safari 的屏幕阅读、技能触控、角色辨识度和性能仍待玩家确认。
