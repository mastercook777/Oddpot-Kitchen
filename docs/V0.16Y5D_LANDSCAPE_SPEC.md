# Y5d · 森林与热泉地貌重构
2026-11-25，Y5c3玩家明确验收成立；PR117 17/17 CI已核实成功。冻结战斗和技能。当前地面平面+圆形路径、边缘低矮重复物，缺少环境组织。
## 范围
- 连续地面网格：真实目标路径以距离场融入顶点色（不再串圆片）；不同尺度的地表颜色、泥土与矿物斑带；可走区域保持 y=0，原碰撞、路径、掉落/警告/角色投影不动。外侧地形连续抬升，远端高、前端低，不挡住玩家；斜坡/断层只在边界外，避免伪碰撞。
- 森林：meadow 浅绿林地、glow 幽光菌群、roots 古木根系/枯木、garden 明亮灌丛。真实障碍内的树木/岩石剪影多样化，林缘分层冠层、地面林下植物沿现有非碰撞景物位置簇生，避开真实路线及节点；高树遮挡处理维持。非互动植物不仿食材拾取圈。
- 热泉：spring 石灰华阶梯、steam 深色裂谷、ember 层叠玄武岩和熔岩纹、oasis 青蓝矿泉与晶体；连续外围岩壁、层理、阶梯水池及动态细水纹（边界外非危险，低调区别真实喷口）。现有危险喷口、怪物、技能维持原样。
- 14个森林/热泉节点用同一确定性渲染层，按 zone/seed 独立变化；不新增地图区块、可走高度、碰撞、互动、资源或经济；默认2D和云港不改。
## 验收
确定性、路线融合、内部高度为0、外部地形连续、无新增碰撞、有限资源；共享网格/实例池控制draw call，重建/销毁释放。真实WebGL截图及320/375/390、地貌诊断、原技能回归；视觉及移动端性能独立玩家验收。Y6餐厅生命感与Z全局UI后置。
