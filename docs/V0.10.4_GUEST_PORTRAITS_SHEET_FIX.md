# v0.10.4 · 客人图鉴像素角色和关闭按钮布局修复

**状态：功能已实现并提交 PR #38，自动回归待验证 / iPhone 真机仍待验收。**  
**基线**：v0.10.3 / main，2026-10-13。  
**缘由**：用户已在 iPhone 真机验证 v0.10.2 客人图鉴，指出头像仍然是 emoji（无法对应营业场景里的 16×24 像素小人），且右上角关闭按钮与「菜谱/客人」两页签重叠；上一轮 v0.10.3 仅改善研发火候与回放，未修这两项。**本修复必须处理完两项，不能用增加剧情或改研发系统代替。**

## 1. 头像直接复用营业中的程序角色

- 以 `src/pixels_v041.js` 的 **同一 `pixelActor(c,kind,x,y,scale)`** 为唯一图形来源。对应现有四类 `adventurer` 铁甲矮人 / `family` 菌帽一家 / `regular` 史莱姆街坊 / `critic` 幽灵鉴味师。不要用 emoji 或另画相似版本，以免主场景和图鉴外形不同。
- 已真正到店并被 `guestDex.seenSegments` 解锁的卡片，用本地 `canvas` 绘制放大的静态像素立绘，`image-rendering:pixelated`，背景为图鉴现有暖色框。
- 尚未遇见的卡片保持「？」剪影，不提前泄露角色；不改变熟客数据、商人资格、交易或存档。
- 以 `src/app.js` 的 `render()` 动态重绘为挂载时点；避免给游戏循环每一帧绘制头像，不需要正式美术资产和打包新图片。
- Canvas 角色按原生清晰像素比例绘制，不依赖外部图片、网络或 emoji 作为已解锁头像。

## 2. 图鉴面板头部彻底分区

当前 `style.css` 的 `.sheet-header` 高 33px，`.sheet-close` 有全局 `.game-btn` 的至少 40px 点击区；`v102-book-tabs` 又紧贴 `sheet-body` 起始处，真实 iPhone 上右上角关闭按钮下压遮挡页签。

- 图鉴专属 `v104-book-sheet`：头部占完整 56px 固定区；中央抓手、右侧独立关闭按钮 **44×44px**，完全在弹窗边框内，不侵入页签行。
- 两个图鉴 tab 在其下方的独立 `sheet-body` 流式内容中，保持 scroll 内 sticky 行为；页签按钮最低 41px，正确 aria-selected 状态。上方多留一点内边距。
- 保留 `data-act="close-sheet"` 现有处理和关闭遮罩、菜谱切换、料理变体选择，不新增入口/弹窗，不改变所有其他 sheet 的原样式。
- 320px 宽、短屏、iPhone 安全区下：关闭按钮始终可见可点，tab 不被遮盖；内容仍能纵向滚动，卡片不横向溢出。
