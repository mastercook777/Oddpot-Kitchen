# v0.14-B · 双面烤架、三道手工菜与烤叉

状态：2026-10-17 设计先于代码入仓；玩家明确暂缓强引导，沿经营内容路线图完成 v0.14.0-alpha.2。PR #72 的 485 项 Node、15 组 Actions 通过（320/375/390 手机 Chrome 与离线），真机体验待玩家验收。

## 玩家体验和解锁

- 获得第二枚万味星章且已有中央厨位后，在成长页以真实金币购买烤架与烤叉组合。烤架是中央厨位的一种可配置厨具，仍只占一个真实工位；换回炒锅/炖锅后保留所有权，重新装配遵循当天原换锅规则。不能在尚未拥有中央厨位时购买，也不能把前两口基础锅置换成烤架而锁死早期菜单。
- 烤架只研发三道手工搭配：野牛蒜香串（牛肉＋蒜瓣）、火椒烤鸡串（鸡肉＋火椒）、林野菌蔬串（蘑菇＋卷卷魔菜＋洋葱）。不为全部普通材料组合自动生成数百道烤菜。主菜售价约 26–37、制作 10–14 秒，以真实材料成本、客群预算和产能审计；高品质和工艺仍从唯一订单快照进入售价。
- 研发时选择烤架、投料，正反两面随时间受热；玩家在合适时机「翻面」，可选「刷香料」改善匹配工艺；夹生或焦糊不得售卖。结果展示正反两面火候、品质和未来订单价格。一个按钮不能代替两面操作。
- 探索装备增加烤叉：中距离窄角自动穿刺，主动技能沿面向直线穿透至多两个目标；与炒锅防御、汤锅远程范围有不同取舍。不购买前不出现，旧在途探索武器快照保持原样。

## 真实系统与兼容

1. `GRILL` 进入现有 `kitchen.slots`、`kitchenPreview`、`createService` 的第三个物理工位，订单按 `recipe.station` 分流、员工/主厨实际覆盖后才生产，单据、食材、工资、XP、售价和报表沿原流水。购买唯一 ledger id；不改变 WOK/POT 的共享熟练等级或老双炉班次。
2. 解锁只对购买后的**新营业**生效；已有 `service.kitchenSnapshot` 不改。旧存档 `ensureKitchen` 兼容未知/缺失的烤架字段，未购买时绝不凭旧中央厨位自动赠送。
3. 研发的真实食材在起锅时唯一扣减，失败也消耗；工艺版本加入现有 `recipeVariants`，菜单/备餐/订单快照/日报使用原接口。菜单没有烤架覆盖时必须阻止开业，但允许免费应急改装恢复可开业状态。
4. 路线、Boss、材料掉落、客群预算、采购量、前两星评分、旧订单冻结都不因烤叉而改。无第三星、门户、水吧或新材料。
