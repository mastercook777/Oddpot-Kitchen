# Z2d.1 · 全局抽屉交互一致性与窄屏可读性
2026-11-26；基线 main Z2c14（PR142 已合并，17/17 CI通过；Pages另核）。状态：设计先行。
## 问题与玩家目标
Z2c13统一抽屉视觉，但 app.js 每次 render 全量重建 DOM，打开、切换筛选、采购与关闭时没有键盘焦点管理，aria-modal 并未阻止后台 Tab。现有图鉴页签40px、变体36px，在窄屏点选偏小。本轮先解决全局共用抽屉，不假称八阶段均完成。
## 范围 / 操作
打开图鉴、库存、菜单、员工、设置等原有抽屉：背景不可交互；焦点进入关闭按钮，Tab/Shift+Tab在面板循环，Escape保持原关闭行为；面板内同一按钮触发重绘时尽可能恢复同一控件，失效时回到关闭按钮；关闭尽可能回到原入口（同阶段），入口消失则不强制跳转。触摸原有点击、滚动与暂停契约不变。通过 focus-visible 提供黄铜色边框，44px图鉴筛选与工艺按钮，320宽度可换行，避免横向溢出。既有3D镜头、Hearthcraft素材、主角冻结、HUD、经济、存档和云港不变。
## 实现
app.js共享 render / click / keydown 逻辑内实现；full_game_ui_v014.css追加限定抽屉样式；沿用离线构建脚本的现有CSS与app.js。无新依赖、无规则和数值调整。版本展示与缓存键对齐；core package 版本不变。焦点仅为内存中的DOM描述，不写存档。非引用抽屉的突发事件等其他对话框不在本轮。
## 验收
- 打开/关闭、同面板重绘、Tab首尾循环、失效控件回退，模拟DOM单测；验证实际源逻辑。
- 320/375/390真实浏览器，触摸图鉴筛选、采购、员工、关闭与返回；键盘Tab与Escape；场景、旧档、完整经营、离线与3D烟测。
- CI、Pages、玩家真机分别记录。后续Z2d其他阶段一致性与可访问性，再Z3音效/转场/质感/性能。
## 风险
Safari焦点/软键盘与 inert 兼容须真实验证；不让焦点改变游戏时间、订单或存档；不要用屏幕遮罩替代键盘约束。若全量回归无法验证，不合并未经确认的功能代码。
