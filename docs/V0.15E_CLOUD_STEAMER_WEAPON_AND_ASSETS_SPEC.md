# v0.15-E · 云港蒸笼成长、控场武器与港口餐厅专属素材

**日期**：2026-10-21  
**状态**：已合并 main（自动验证完成；Pages/玩家实机待确认）  
**基线**：`main` / `0.15.0-alpha.4`，沿用 v0.15-C 的本地餐厅、物理厨位、独立账本与跨章迁移。

## 玩家反馈与目标

1. 蒸笼买入后「升级厨具」里没有升级选项。源码 `COOKWARE_UPGRADE_COST` 和 `cookwareUpgradeCost` 显式排除了 STEAM，虽然 `ensureKitchen` 已存储 `mastery.STEAM`。
2. 云港营业场景仍重复边境店的桌椅、炉台、内饰图元，仅浮岛底景与配色不同。需要**实际轮廓/材质/道具不同**的当地经营素材，而不是 CSS 滤镜或地图换色。
3. 云汽蒸笼不能在探索选作武器；必须与炒锅（近身扇击/格挡）、深锅（远距投弹/爆破）、烤叉（穿刺/喷焰）在战术职责上区别明显。

## 1. 本次确定的可玩设计

### 1.1 蒸笼升级：云汽导流器 Lv2

- 解锁与门槛不变：**云港一次真实探索返程后**，成长页支付 85 金币购入云汽蒸笼 Lv1；旧档已经购入的直接认可。
- 新增 **STEAM Lv1→Lv2 单次升级，花费 95 云港金币**，与 WOK/POT/GRILL 使用相同的厨具类型经验上限和唯一交易键 `cookware-upgrade-STEAM`。需已拥有蒸笼，只在当地可购；Lv2 不回填旧夜/订单。
- 经营：装在任意现有物理厨位的 STEAM 出餐从原时间减 **2 秒/单**（通过既有 `stationDuration` 的 slot level 权威值）；不改变售价、顾客偏好、原料消耗、上架权限或第二个隐藏厨位。
- 探索：该类型的 Lv2 共享同一个 `mastery.STEAM`，在未安装蒸笼时仍可作为已购入的随身备用探索武器，营造投资回报；两章资金/技能独立。

### 1.2 探索第四武器：云汽蒸笼 = 近中距离持续控场

- **只有云港拥有蒸笼时**可以在出发前选 STEAM；进入关卡后冻结武器 `type/level/attackId/skillId`，中途修改厨位不影响本次 run。
- 自动普攻「云汽涌流」：无需面向敌人，**以玩家为中心 1.60 格范围**（Lv2 1.90 格）每 **0.96 秒**（Lv2 0.78 秒）脉冲至多 **2 名** 最近且无遮挡目标，每人 1 伤害并短减速 **0.9 秒**（Lv2 1.25 秒）。比炒锅近身范围略远，但频率慢，无格挡、无远距离投弹、无扇面集中击退，也不可穿墙。
- 主动技能「凝雾结界」：6.5 秒冷却，**在当前位置**留下一片半径 **1.9 格**（Lv2 2.15 格）、持续 **2.8 秒**（Lv2 3.4 秒）的半透明云雾区域。技能本身不直接扣血、补血、发奖励或制造库存；范围内持续降低敌人移动速度，利用现有 `slowTime`（Boss 不免疫但不改变攻击预警/飞弹速度）；玩家可利用雾域控制追击并绕行采料。释放无需敌人；雾区与原世界探索不会混入。
- 视觉：新增专用像素蒸笼实体（竹编环、金属云汽阀和双层笼盖，Lv2 的铭牌/导流翼）、圆形雾浪自动攻击、环带/云朵漂浮的平滑特效；沿当前「像素人物/器具 + 非像素特效」规范。**不得把 POT 锅贴图、GRILL 火焰直接替换颜色当做 STEAM**。
- 保持原 hp、Boss 机制、地图风道、敌人掉落、现有三个武器伤害/冷却。现有旧档的 `STEAM mastery` 默认为 1，已装备旧武器不丢失。

### 1.3 云港经营专属视觉素材（真实场景几何不同）

- 创建独立的程序化 Canvas 素材模块 `src/cloud_diner_assets_v015e.js`；不要引用外部不可控贴图，也不要使用像素特效。
- 采用可辨认的**悬挂船帆/缆绳/锚扣/吊装货笼**作为中上层道具；港口地面为悬浮拼接平台，保留真实碰撞区域；桌椅改为**六角玻璃晶石面+吊装支柱+云港座凳**，不只是旧方桌换青色；蒸笼厨位显示真实**叠层竹笼、蒸汽管和阀门**。港口吊灯、食材货箱等作为静态局部素材，不能遮挡订单文字和角色，也不能暗示可碰撞的假入口。
- 实际 Canvas 坐标仍以 `dinerFloor` 的桌椅/炉台/门口为唯一位置权威。客人入座、上菜、跑堂、主角碰撞不改；仅替换云港当地的渲染几何。原店原图不变。
- 若经 CI 实测手机窄屏遮挡则缩减装饰，而不是扩大可碰撞实体。

## 3. 测试与交付门槛

1. 新云港档购蒸笼→Lv2升级：金币分别正确扣 85/95，交易各一次，装配工位每单原时长减 2 秒，与原有 WOK/POT/GRILL 原规则一致。
2. 旧云港已购入蒸笼的存档可升级；往返原店后本地金币/厨具等级/交易账本都正确恢复。未购入、原店、非升级阶段不能升级。
3. 购入后云港出发选择出现独立 STEAM（包括背包备用）；新旧武器可以切换；冻结等级，Lv1/Lv2 普攻/技能的半径、冷却和减速不同。
4. 普攻最多打 2 名、受墙遮挡，无虚假墙后命中；雾域原地释放 2.8/3.4s，范围内追兵真实减速，离开恢复，不增掉落、不修改 Boss 伤害规则。
5. 正式画面云港桌台/座凳/器具/货舱素材确实独立于原店，真实订单与餐厅碰撞不变；iPhone 320/375/390 CSS/Canvas 及离线入口回归。
