# v0.15-C · 云港浮岛重制规格

**背景**：玩家 2026-10-20 试玩 v0.15.0-alpha.1 后指出新世界换皮、旧员工穿越、两厨位三厨具、异界旧菜上架、图鉴混杂及旧店缺少回访意义。本规格覆盖旧版 `V0.15B` 中「同行员工直接入职」「旧菜自然受供给限制」等判断。第三星和首扇门已经合并；本轮是这两个功能的质量返工。

## 世界辨识度和战斗

- 餐厅保持已验证的工作站、桌椅、碰撞与真实订单坐标，但换成看得见下方云海与远景浮岛的开放边缘结构：悬空栈桥入口、绳索栏杆、浮空港帆、蓝白石面、云影和缓慢流动的雾。场景在空店、备餐和营业一致，角色与可互动范围不变。移动端三种窄屏依然可辨。
- 野外必须有可辨识的断桥／云海空隙、风流方向及浮岛轮廓；仅换地砖颜色不合格。崖缘通过障碍／危险格表达，不绘制成可以穿过的通路。风道形成可预告的侧向推力，玩家可借力移动或逆风绕行，不能无预兆把角色推出地图。
- 当地常见怪不再调用旧火椒直线弹：阵风蛾先浮起示警，再释放横向漂移的风刃；玩家能从示警方向判断安全侧。风暴首领不用旧扇形、冲刺、圆环模板，改「定向横扫风墙 → 留出可绕开的安全带」「短时吸向中心 → 外圈雷击」的两阶段组合。伤害、碰撞、预警与视觉同源，掉落风暴晶核仍只记一次。

## 当地经营约束

- 原食堂员工留在原食堂。云港首店由当地帮厨「阿岚」值守，跑堂「小羽」和后续第二帮厨「小栖」只在当地雇佣。角色造型和 UI 名字与原店区分；XP/等级分别储存。已经进入云港的存档首次迁移：当地帮厨保留已开始的当地工作经验，旧店员工的经验不再同步；不追扣、不重付既有工资。旧店原样保留。
- 菜谱知识和图鉴可跨世界查看。**可上架**必须同时满足本章可持续供应原料、厨具已经拥有、以及菜谱已研发；云港只开放当地四种常材、少量共有基础食材（鸡肉、洋葱）及风暴晶核。旧菜即使仓库偶有旧库存也只能在图鉴浏览，不能进入菜单、隐藏菜、员工餐或营业临时换菜。旧档菜单迁移为当地可做的开局菜／空位，绝不静默开业或虚构营业结果。
- 两个物理厨位只能同时承诺两个厨具类型。云汽蒸笼是可安装在深锅位的独立模式，同一深锅位选择普通炖锅或云汽蒸笼供当晚营业；炒锅、炖锅、蒸笼、烤架共四类，第三类菜必须换菜单或拥有第三厨位。菜单挑选时显示需求厨具和当前覆盖状态，开业前再由引擎强制校验。已开始营业的快照不改写。
- 图鉴在「菜谱／客人」下面按炒锅、炖锅、蒸笼、烤架分类；云港可翻看旧菜并明确标注「仅原食堂上架」，不提供无效的上架入口。未知配方继续保留原有发现线索。

## 回访原世界的用途

- 云港开启后原店仍可经营。原店实际完成一个营业日并至少卖出一份料理，才能获得一张「航运委托」凭证；每个原店营业日最多一张，唯一账本记录。云港市场每当地营业日最多用一张换取少量当地常材的补给单，不能换 Boss 材料，不能搬运金币／旧菜／整仓库存。采购与兑换是玩家选择，不设强制回旧店门槛。
- HUD／传送门显示两地各自目标和补给凭证；往返仍仅在安全阶段，原店报告注明这张凭证来自真实营业而非切换奖励。旧世界是对新世界的可选后勤线，本地探索和市场仍能独立支持首枚云港星章。

## 验收

1. 新档和 v0.15 已进入云港的旧档：旧员工不会在当地值守；各地 roster/XP/金币/星章独立，不克隆交易。
2. 三厨具两厨位的菜单不能开业；旧菜不能通过菜单、隐藏菜、员工餐、波间换菜绕过边界；图鉴仍能看到。
3. 原店真实服务生成一张凭证，重复结算、无成交、单纯切换都不生成；云港每日兑换上限、材料入库和 ledger 唯一，返回后各章余额正确。
4. 移动 Chrome 320/375/390 及无构建静态 Pages 模式检查可见浮岛餐厅、风道与新怪攻击、独立当地员工、菜单厨具提示。iPhone 手感和视觉由玩家真机再验收。
