# v0.5D｜经营现场反馈与路径修复

## 来自 v0.5C 的玩家反馈
1. 顾客离席仍穿桌：使用五段固定动线（入口→中央通道→外侧转角→桌外侧→座位），离席沿逆序走，座位在离席完成前不得重占。
2. 跑堂门口瞬移：每个营业时间块绑定稳定巡逻，出发点与终点一致，不因新的顾客到达事件突然切换目标。
3. 看不见顾客点什么：在每位等待顾客头顶显示该单菜品简名，保留耐心圆环，点击座位看订单详情。
4. 看不见缺料：通过只读 `serviceSupplyStatus()` 对待做订单及真实库存/预制做需求预警，缺料时明确显示材料和菜名；已失败订单的警示停留 7 秒，营业账本不受显示逻辑影响。
5. 人数和目标感受弱：发现原随机计划的 `rand(key)%5` 由于 LCG 乘数可被5整除，所有 seed 都落在同一种主题。改为高位取模，五种主题匹配 6–11 人范围、到店间隔和客群倾向，UI 显示到店/总人数、待做数、制作中数，以及实时目标进度和达成祝贺。

## 技术边界
- 保留两个双人桌、两厨位、员工餐、经营事件、第三日厨王、三菜菜单和原存档键。
- 不改变经济交易路径：出餐/食材消耗/事件支出/目标奖励仍由 engine 权威裁决；视觉显示与动画不得额外扣款。
- 旧存档未记录 `leftAt` 时不保留永久占座；下一营业夜重新生成新主题。
- 本次没有重做料理研发（计划 v0.6），也没有引入更多经营按钮或雇员。
