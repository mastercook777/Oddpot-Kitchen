# Oddpot Art Bible v1.0 · v0.16-A2.0
2026-11-24 · 用户确认《夜勤人》式方向，A1 场景优先方向通过，画面精度未通过。主线基准 PR #95 / 15c63e7（0.15.0-alpha.11）。
## 1. 美术身份
目标：立体化 2D 奇幻绘本环境 × 清晰精细像素人物/食材 × 平滑光影与动态特效。主要参考《夜勤人》室内外共用的俯视空间表达；《风来之国》参考细节与光色，不复制任何原作资产。Oddpot 的识别点是奇幻厨具、食材生态与温馨边境食堂。不是等距 45°，不是真 3D，不迁移引擎。游戏逻辑保持原二维坐标、镜头、碰撞；不得旋转战斗输入。
## 2. 统一投影与尺寸
采用正向斜俯视（屏幕 x 向右、y 向下；家具前立面可见；垂直高度向屏幕上方延伸），不实施全局 y 压缩以免操作位置错位。地面接触点为锚点，物件顶部可超出碰撞轮廓，角色按脚底深度排序；森林现有地格 1×1，树干根脚 .5/.5，冠幅可超出；餐厅仍以 DINER_FLOOR 归一化坐标为准。画面上主角和家具必须有自然相对尺度。现有像素角色共用 pixelActor，保持固定比例和动作可读，不在 A2.0 强制改全部 sprite；后续角色规范目标 24–32px 原生设计（具体以双场景验证定稿），整数像素缩放优先，避免混用多种像素网格。
## 3. 光色与材质
光从左上方，阴影往右下。边境木材 #785039/#ad8052/#e0b77a，暗部 #302b26；森林叶深 #294b3d、主 #527952、高光 #a0b57a，土/树皮呼应室内暖木，石材冷灰绿 #66766d。减少无意义亮色、全局轮廓描边和随机纹理；可交互物件对比高，装饰弱，拾取/危险预警优先。不使用全屏模糊来伪造质感。环境纹理有结构，木板有接缝与端面，石砖有砌缝，树有根脚、树皮、分簇叶片和阴影。
## 4. 分层与资产
L0 地面/建筑，静态尽可能缓存；L1 接触阴影；L2 独立道具（桌椅、柜、锅、树、岩），以脚底锚点绘制；L3 角色、订单、物品等真实实体；L4 前景遮挡和可读反馈；L5 灯光、特效及 UI。严禁把可扩建家具烘焙进完整背景。A2.0 可先用作者设计的可复用矢量路径/程序素材验证形体，不能称为手绘成品；A2.1/2.2 继续建立透明独立美术素材与原生角色规范。资产命名 region_category_variant_state；登记逻辑锚点、可视边界、遮挡及许可，禁止未经授权复制参考游戏。
## 5. 双场景切片顺序
A2.0：确定上述标准并先做实景试验（边境 forecast 与 herb_path 晨露森林的已有正常探索；不碰云港/其他生态）；相同暖色材质、接触阴影、立面和高度。A2.1：边境环境与独立家具正式精修；A2.2：森林环境与树/岩正式精修，检查战斗可读；A2.3：同主角、同光色、出门—探索—返回的实机对照。A3：动态厨位/扩建/昼夜及正式集成；A4：繁忙营业验收；再继续 B–F。A2.0 的程序切片不是正式资产完成。
## 6. 工程及性能
Vite + Canvas 2D，保留所有经济、存档、AI、碰撞、地图与订单状态。只新增表现模块或隔离函数，固定随机纹理；避免每帧大规模生成，缓存树/背景等静态素材；尊重低端手机及 reduced-motion。现有 standalone 生成脚本和在线版本一致。优先修复 A1 回归阻断，不能把过去失败的 CI 写成通过。版本标识与缓存独立核查。
## 7. 验收
320/375/390 宽度与同种子截图，餐厅真实桌/锅数量一致，森林仅 herb_path 生效，碰撞与攻击、危险提示、可拾取物不变；无新存档字段，旧档无迁移。真实测试及未测项逐条记录。玩家观察：两处截屏是否像一个世界；人物/物件比例；形体是否有明确立面、接触影、遮挡；是否显著区别 A1；森林战斗是否更难读。只有两处均验收才推广。禁止用一张概念图宣称游戏实际效果。
## 8. 决策
先二维立体化，不换引擎；用户确认《夜勤人》方向。所有新世界与新增菜谱暂缓，云港保持现状。正式美术基线仍待玩家确认。
