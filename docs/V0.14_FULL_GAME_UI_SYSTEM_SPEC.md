# v0.14 · 全游戏界面产品化与信息层级

状态：设计规格先于功能代码提交；v0.14.0-alpha.1 第一轮全游戏 UI 已在 [PR #71](https://github.com/mastercook777/Oddpot-Kitchen/pull/71) 实装并完成 CI。玩家 2026-10-16 明确范围是**整个游戏 UI**，首轮只是验收入口，不是改版范围的终点。

## 现状与目标

v0.13.0-alpha.9 的首页已经有真实餐厅 Canvas，然而首页任务卡、首日说明、资源行、快捷入口与主按钮并列；路线、研发、菜单、备餐、日报各自延续密集的说明和卡片。实看线上新档，从首页到备餐一直需要阅读多个文字区才能判断下一步。服务和探索的即时玩法已有场景基础，应保持画面与操作区清楚。

本轮统一所有阶段的游戏语言：**场景与人物承载氛围，一屏突出当前决策，结果直接显示收益与代价；详细规则按需展开**。不改真实引擎、经济、菜谱售价公式、库存、订单快照、摇杆与存档 schema。

## 全流程页面契约

| 场景 | 玩家要看到的主要信息 | 主操作 | 次要/按需信息 |
| --- | --- | --- | --- |
| 开店前首页 | 活餐厅、今日目标与预期客流 | 出门取材 | 采购、便当、图鉴；更多说明收进目标牌 |
| 出发准备 | 库存缺口、区域、采集/狩猎两条路线 | 点击路线出发 | 厨具选择及路线细节仍可读，但不以长段落压过选择 |
| 野外实时、分支、奇遇 | 场景、血量、背包、风险与当前事件 | 移动/技能、二选一/撤离 | 保留同源 Canvas、触控安全区与可滚动事件卡 |
| 研发准备、烹饪、结果 | 食材、锅具、火候；结果要突出品质、售价、耗时与原价差额 | 下锅/起锅/再试 | 逐步复盘、员工餐与便当用途收进可展开详情 |
| 菜单 | 三道料理各自售价、耗时、可做份数及主共鸣 | 换菜并确认 | 原料共享/复杂工艺说明按需展开 |
| 备餐 | 真实厨房、锅具覆盖、缺料警示、员工和揽客 | 开门迎客 | 预制、工资与营销规则折叠到相关选择 |
| 营业 | 餐厅实时人物/订单、波次、上菜数、当前目标 | 场景内服务动作 | 事件决策保留暂停与完整可点击选项 |
| 日报、成长 | 今晚结果、目标是否达成、最重要的下一步建议；可购买成长 | 结束本日/开始次日 | 账本、逐单工艺、员工明细与全部成长项目可滚动阅读 |
| 图鉴、市场、员工、设置等抽屉 | 当前选择的对象与价格/库存/效果 | 各自唯一确认动作 | 不占主场景；保证关闭、滚动与焦点可用 |

## 视觉与交互约束

1. 统一顶部日程、资源与阶段标识，移除玩家无关的常驻版本号和图鉴总数；设置中保留版本，图鉴里保留收集数。普通阶段可见轻量步骤轨迹：备料、研发、菜单、开店、结算。不能把分支或旧档阶段显示成尚未完成的强制任务。
2. 主色沿用深绿、暖木和金色，边框、字级、按钮动效统一；大块泛用网页卡改为招牌、菜牌、收据、炉台等游戏内物件语言。现有像素人物和食材、Hybrid 探索环境继续同源，不引入外网美术。
3. 每个非实时页最多一个主要按钮；次要入口视觉降级。重复解释可折叠，但关键风险（缺料、不可制作、付费和不可逆选择）必须在操作前直接可见。底部操作固定，内容只在自己的容器滚动。
4. 以易读和触控为先：320×568、375×667、390×844 竖屏无裁切；主要命中区至少 44px；短屏滚动可到末项；动态效果遵循减少动态效果设置。
5. 全新存档旧的可跳过首日文字引导在这一轮先压缩为单动作提示；交互锁定、聚焦、暂停第一单等“偏强制引导”作为下一开发切片，必须基于最终 UI 坐标和真实引擎状态，旧档不自动触发，始终可跳过。

## 实施范围与验收

- 本 UI 切片覆盖上述**所有阶段及常用抽屉**：先统一壳层与场景，再逐页移除重复说明并强化可见决策；包含研发价值对比和可展开复盘。不得把只改首页称为全游戏改版。
- 任何展示售价/耗时/可做份数的地方从 `recipeCraftSnapshot`、`recipeAvailableServings` 等现有事实源读取；提示不增加虚构利润或保证销量。
- 回归新档、旧档、研发成功与失败、探索分支、菜单替换、备餐缺料/锅具不足、营业事件、日报与成长、市场/图鉴/员工抽屉；Node、构建、离线包及三手机视口。游戏平衡、强制引导流程另立规格与版本。

## alpha.1 实施与回归（2026-10-16）

- `src/app.js` 统一顶部资源、阶段轨迹、主次按钮与当前任务；首页缩短导览并保留真实厨房，出发路线、研发价值结果、菜单售价/耗时/份数、备餐员工与营销、营业事件、日报收据和成长入口按上述契约重排。日报账本、逐单工艺、营销详情等仍可展开查阅。
- `src/full_game_ui_v014.css` 给全部阶段和常用抽屉使用同一套招牌、菜牌、收据、厨房场景、触控和短屏滚动规则；`index.html` 与独立离线版同步到 v0.14.0-alpha.1。旧档市场升级仍在首页执行，阶段内容刷新保留局部滚动位置。
- 481/481 Node 测试、Vite 构建、离线包构建以及 PR 的 14/14 Actions 通过。新增手机 Chrome 320/375/390 三种宽度覆盖首页、探索、研发、菜单、备餐、营业、日报和成长的截图与交互；旧经营、市场、队列、首日引导回归亦通过。CI 截图运行器缺中文字库，自动截图中的汉字为方框，故**不能用它验收中文字形**；真机视觉和易用性仍待玩家体验。
- 下一切片先制定并实现基于真实操作的偏强制新手引导：逐步聚焦、限制当前任务外的跳转、事件安全暂停、完成动作后推进；旧档不突发开启且可跳过。该引导尚未包含在 alpha.1。料理经济数值的进一步多日校准也单独处理；本轮呈现现有真实售价差异，不改变经济公式。
