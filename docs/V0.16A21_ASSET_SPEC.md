# v0.16-A2.1 · 边境食堂素材落地
2026-11-24 · 玩家认可第二版《夜勤人》式概念设计板，授权真实落地。基线 A2.0 / Art Bible v1.0。
## 目标
不再用矩形拼接假装正式美术；把已认可原创概念板右侧独立物件样例提取为可用透明像素素材（桌、凳、炉、炖锅、食材柜、桶、菜箱、灯、地面墙面等）。第一批可玩资产验证，不是整张概念图直接作为背景，不复制参考游戏资源。
## 规则与范围
边境 forecast 先接入；真实 DINER_FLOOR、桌位数、锅具类型、场景入口、人物、存档与经济保持。独立桌凳和炉具随状态画；缺少的烤架保留原表现；其他世界、营业、探索暂不改。不得在原背景上重叠假桌椅。概念板角色仅参考，后续正式四向 sprite 单独生产。素材图无文字、无 UI；裁剪去底，像素采样，保持原形体，记录各源区域和绘制锚点。PNG atlas 嵌入 JS data URI，在线与离线同源；加载未完成时保留原 A2.0 绘制兜底。
## 验收
真机首屏能明显看出实际像素纹理，木/石/织物和家具一致；桌、椅、锅具实际数量和交互不变，320/375/390 不遮挡入口；加载失败有兜底、离线同样可见；不改变规则。测试与发布各自记录。下一批 A2.1d/e 继续正式背景、完整锅具和营业表现；森林 A2.2 待本轮验收。
