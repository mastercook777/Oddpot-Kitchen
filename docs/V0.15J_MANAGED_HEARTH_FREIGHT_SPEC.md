# v0.15-J · 边境食堂留守航运 MVP：真实库存定期转运

**日期：2026-10-25**　**状态：代码与专项测试已提交 PR #94，569/569 Node 核心测试通过；完整 Actions/合并/Pages/真机待核**　**基线：main alpha.10；分支 alpha.11**。

## 背景与优先级
[v0.15-D 审计](V0.15D_CLOUD_OPERATIONS_RESULTS.md)发现不出门仅市场采购时平均每晚约 2.69 单缺料，单次旧世界八份委托不是长期供给。本迭代建立旧店留守商队真实仓储转运能力，但**不是后台凭空生产的“自动经营收益”**，以免出现无限原料并冲淡旧世界亲自探索价值。

## 可玩主循环
1. 原世界三星解锁传送门且已真实雇佣至少一位边境员工后，到云港食材采购面板开启「旧店留守航运」。选择货物偏好：香辛（火椒×3、蒜瓣×2、洋葱×1），菌香（蘑菇×3、鸡肉×2、洋葱×1），野味（牛肉×3、土豆×2、鸡肉×1）。
2. 只在**真正完成一夜云港营业并结算日报**时计 1 次航期。每结算两夜才尝试调拨一批，正常上限6份，*从旧店现存库存按偏好逐项扣减*（不足则只装实有数量，不临时造货）；旧店以旧店金币支付10金币运费，付不起、零食材则不发货且不扣款、不清空已经完成的船期。
3. **最多待领取1批**，有待领取时不发下一批、不累积多批。收到货物后再完成两个云港真实营业日才能有下一批；仅传送门来回或现实时间变化不推进。商队在日结后发车，云港次日采购阶段可点击「领取旧店物资」。
4. 旧世界仓库扣货与独立老店 ledger `managed-export-out-N` 写入旧世界持久快照；全局 `managedFreight` 记录连续发货序号、等待船期、偏好及待收运单；云港独立 ledger `managed-export-in-N` 记录真正入库，领取双击、重新进货窗口、跨世界存读档都不允许额外生成材料。
5. 已运行的旧券 `ferryCredits` / 每个云港营业日最多一次八份委托维持原状，新的6份限量托运并行而不覆盖委托；云港本地材料仍从探索/商店取得，禁止在托运中携带云港材料、Boss 特产或旧食谱直接上架权限。
6. 玩家主动回旧世界：可继续经营取得委托、补仓、赚钱、升级、探索稀有材料；**当前版本的旧店只执行从已有仓库的转运，不虚拟计算每日自动营业/采买/员工工资**。后续若增加自动营业，先做真实员工排班/原料/工资/欠薪/净利与多日审计。

## 安全边界
- 所有更改发生在同一个内存存档根对象中，先验证两章状态/库存/旧世界运费，再修改旧世界仓储和两章 ledger，最后保存整个对象；失败不部分扣库存。每种材料实际出库量必须与待运单完全一致。
- `managedFreight` **全局字段**，不得加入 `LOCAL_CHAPTER_FIELDS`；旧城金币仓库/员工/ledger 均在 `worlds.hearth`；云港主对象仍保有其本地账户及库存。断档旧存档按需生成默认值而非重置。
- 发车只有 `closeService` 已经过真实营业一次性 `reportBuilt` 守卫才触发，不修改实时服务途中的存档；首次存档初始化不赠物资。
- 领取限制云港预告/研发/菜单/备餐/已结束探索阶段，防战斗/营业中凭空添加库存。领取的 `transact` 使用唯一 inbound ID；若外部旧档已有该 ID，重复读入残留运单必须安全清除且不重入账。
- 兑换 / 运费入旧世界账本只包含真实转运，不作为自动销售、旧店营业报表收入或额外航运委托；不支持回档复制/同一账本重复 id。
- 预计金额/天数/真实库存和所需剩余船期在 UI 看得到；不要为了复杂系统增加巨型弹窗。手机窄屏可折叠，以现有市场 overlay 样式，按钮有禁用理由。

## 验收
- 开启时检查老店已雇员工；非云港、未解锁、没员工、无旧城快照不能激活/更改。
- 2 次真实 Cloud closeService 发一批；一次日结不能刷两次，门来回和 advanceDay 不推进；零库存/旧城币不足不动钱/库存；补足后可于下次真实日结重试。
- 旧仓只有部分材料时只有实际出库量（1~6），6件上限；运费10只扣老店；同一批 pending 时额外天数不会产生出库/运费。
- 领取相同批次两次、存读档后再领、跨回旧世界再来，原店仓/云港仓与 ledger 绝无重复。
- 各类旧材料可用作 v0.15-H 融合菜真实研发/菜单配菜，云港原生/首领掉落不被托运；无旧菜越权解锁。
- 真实 Node 回归、移动 320/375/390 Chrome、Vite 生产构建、在线/离线缓存与表现一致，Pages/iPhone 玩家验收独立列明。运行至少12个双世界模拟样本，衡量平均发货件数、旧世界库存减少与运费、云港可做菜数和缺料。
