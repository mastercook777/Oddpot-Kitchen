# v0.13-E · 真正可见的每日四款采购修复（2026-10-15）

## 用户复现与根因
上一版v0.13.0-alpha.4虽然在`ensureDailyMarket`实现了8种普通食材每日选4种，但`src/app.js`仍按`ING.acquisitionPolicy==='SHOP_STAPLE'`固定只画鸡肉/蒜/蘑菇/卷卷魔菜四格，未抽中的商品还会显示「今日缺货」。真实抽中的牛肉/火椒/洋葱/土豆被错误绘制到「探索获取」且缺少购买按钮。最初界面文案依旧写「每天3–4种、至少6份」，旧`schema2`存档当日还可能仅有3格。玩家核查属实。

## 真实可验的产品规则
- 每一营业日准确随机上架**4种**，从8种普通食材抽取；当日上架名单在存档/刷新后不变，次日换货。
- 四格每格**有实际正数初始可买量**，可购买1份或3份，单价和余量显示真实`market.goods`；库存卖完后允许显示「售罄」（符合限量规则），不再显示缺货第5格。
- 无关的未上架商品**不出现在今日上架列表**；移除「今日缺货」作为机制和画面。单独的原料仓储摘要只读，不与采购列表混合。
- 新市场保持平价可售种6–9份、原野外来源可售种2–4份加价。不改变真实库存/币/交易流水/探索材料/二星评鉴；准备阶段的可采购短缺判断必须使用`market.goods`而非旧4常售名单。
- 旧`schema2`及未带schema的当天市场保存中的供货项目、实际余量、价格和已购买原料不得重置：已有1–3项则**保留并补足**到4项；已有4项维持当天项目。迁移时不免费补货卖完商品。下一天按新8选4名单完整刷新。迁移成功升级`schema=4`，避免反复补货。
- 复归准入包括：旧存档3种补4种，旧4种保持不变，新的4种包含真正可买牛/辣椒/土豆/洋葱，每日自然跨天变换；手机版看见4行商品及可点击购买，购买后余量/金币准确变化；320/375/390移动Chrome与单文件离线包均要实机脚本覆盖，不允许仅测纯算法。
