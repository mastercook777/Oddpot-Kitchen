# Z2c9c · Kett 大形体精修
2026-11-26；基线 PR135/b9e55b5，17/17 CI通过。玩家对照已认可的概念图正面与Z2c9b实际正面，要求直接落地到角色工坊。
## 目标与范围
相比b版圆脸、平面杏仁眼、桶形躯干、面包帽及同等发束，c版优先大形体：缩小头部相对肩宽，方圆下颌/眉骨/面颊有实际曲面深浅，窄而有力但不凶的眼、偏笑；倒梯形胸肩、收腰、短夹克与外扩手拳；帽冠高低分区，主发束上扬与次发束向后，留出额头。以实景参考为准，不加无关配件。保留b版及之前对照，工坊默认c正面，同灯光同尺度，增加正面/近景及游戏小尺寸验收。正式游戏仍Z2c8，不动玩法、存档、动画节奏、战斗、其他角色或引擎；肩肘腕锚点维持共享rig契约。 
## 实现
独立three_z2c9c_kett.js，沿用b版参数曲面、脸部贴片投射、扫掠与动作接口，更新面部形体与反解参数、衣身/手和帽发网格；不使用生成图代替真实模型。不宣称高精度资产。
## 验收
真实Three裸模型边界、所有几何坐标有限、四厨具两等级248姿态及双握点，工坊六代切换、四角度、近景、小尺寸、截图。CI、Pages与玩家审美分开核实；若线上未就绪提供实际模型代码的独立预览。待用户反馈再决定下轮。
