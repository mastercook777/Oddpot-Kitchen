## 核心闭环
1. **固定工资＋可选上班。** 雇佣员工可在开店前上岗/休息。上班提供真实 `crewEffects` 并有固定日工资；休息不给Buff、不收本班工资。按已创建营业班次的冻结快照日结仅一次，重入/恢复/旧档无重复扣款；工资资金不足计入待支付账款且金币不低于0，未来营业结清（没有无路可走的破产锁）。
2. **订单经验与晋升。** 阿火仅实际完成帮厨工单获得经验；小芽仅真实完成跑堂送餐并成交的订单获得经验；日报记录今日XP＋累计进度。Lv1→2累计8XP、Lv2→3累计30XP，晋升需玩家在准备或成长页手动确认，晋升时训练成本及日工资台阶；食物原有最多三次熟悉度不丢弃。新晋升不会让锅的最大提速/客人耐心突破既有封顶。Lv3强调晚高峰实际工作专长并可由记录验证。
3. **开门前付费营销（四选一，含默认免费）。** 自然客流0；街头传单18/2名家庭街坊客；公会告示35/3名冒险者；首星品鉴邀请45/1名鉴味师。明确在准备页选择，开业才冻结并付费。实际 `serviceDayPlan` 增加真实有顾客ID、到店、占座、厨房工单、消费、反馈的访客，不自动增加收入；场地扩建自然改善拥堵下宣传收益可能性。队列保持三波且不会让原有客单错位；上限只为实际宣发额外几单开放，天然基础客流仍原上限14。可真实失败、自然营业保持安全路线。
4. **两种经济视图。** 日报利润=实收-原料消耗估值-员工餐-招待/事件-广告-当班应计工资（历史欠薪清偿只计现金，不再重复作为当期费用），每日实际现金变化单列，包括市场支出与晋升、锅位扩建；现金购买只扣一次，防止双扣。
5. **兼容与真值。** v4旧档迁移；已开业快照不重新派员工/营销；重启与重复关门、事件恢复幂等。UI紧凑，320×568可读，所有按钮有真实响应。C1-C3只改变餐馆经营，不更改探索掉落或第2星章（另做）。
6. **开发验收。** Node全量自动回归、真实引擎固定种子模拟宣传新增到店/成交/供应压力、首批80种子7个产能/宣传/缺料组＋既有v0.12-B 21天市场供给测试；完整21日C版现金成长仍须在后续专项校准；GitHub Chrome浏览器检查交互与控制台，合并后通过已配置 Pages 部署并核验。真机仍需玩家反馈，不得凭CI声称真机通过。

## 80 种子经营实验：冻结库存与固定主厨策略
条件：成熟第3轮、声望20，充足材料（缺料组除外），双锅原Lv1、三菜单`chili_meat/chicken_stew/mushroom_stir`品质82；主厨固定POT，阿火WOK、小芽跑堂，`walkable:true`，真实三波服务/结算，所有订单通过现有引擎实际发生，事件用相同低费用选项。不能据此推断普通玩家触摸操作的胜率或探索供给。

| 方案 | 计划客数/平均完成 | 宣传实际成交 | 平均经营利润 | 日内现金净变动* | 平均帮厨/跑堂工作XP |
|---|---:|---:|---:|---:|---:|
| 四桌双员工·自然 | 11.25 / 10.20 | 无 | **126.17** | +216.93 | 6.49 / 10.20 |
| 四桌双员工·街头传单18币 | 13.25 / 11.34 | 1.45 / 2名 | **117.19** | +220.47 | 7.49 / 11.34 |
| 四桌双员工·公会告示35币 | 14.25 / 12.05 | 2.08 / 3名 | **114.63** | +235.25 | 9.40 / 12.05 |
| 两桌双员工·街头传单 | 13.25 / 11.15 | 0.63 / 2名 | **128.06** | +232.20 | 7.26 / 11.15 |
| 四桌双员工Lv2·街头传单 | 13.25 / 11.75 | 1.36 / 2名 | **119.90** | +223.53 | 7.54 / 11.75 |

| 四桌无人上岗·自然 | 11.25 / 3.48 | 无 | **36.44** | +83.40 | 0 / 0 |

*这里的“现金净变动”没有购买食材的真实市场支出，因为实验起始直接给予充足/受控库存。数值并非真实21日净盈利，不可与单位原料估值利润混同。

**设计结论：** 宣传真实增加需求，也增加实际成交，但可能挤占原有订单：四桌自然10.20单，传单11.34、公会12.05。以本受控菜单/工位看，传单/公会的**会计经营利润略低于自然营业**，并不能宣称“广告已实现高利润正循环”；可通过更匹配的菜单、备餐、采购、员工升级优化，仍需后续不同场景更大范围模拟。四桌对新客服务优于两桌（同样传单，实际宣传成交1.45 vs 0.63），显示四桌开始有真实运营价值。Lv2提升总完成数，涨薪抵消部分利润；完整员工成长需要真实玩家反馈。低库存宣传无法带来成交，这是风险真实存在而非伪消费。休班无工资但固定不移动主厨能力受限，不可推广成“自己经营必然差”。

## 特别边界与后续风险
- **费用不等于负面税收**：上岗工资按班记应计，没现金则产生可跨日清偿欠薪而不负金币；选择免费宣传、休班和探索可恢复。第1–2营业日不会强制房租或店铺维护费。
- 玩家原`meals` 3次羁绊+当日菜谱Buff保留；新`xp/level/onDuty`平滑迁移，工资升阶仅付费晋升后发生，实际完成工作才有XP；旧营业快照不会重新收费。
- C版未实现第二星章、第三炉台、熟客广告解锁、更多员工职业；它们需在玩家验收经营成长之后继续推进。
- Chrome自动化通过≠iPhone实际触控、UI阅读和体验已验收；本轮宣传档位和XP阈值为**试玩首发参数，仍可调节**。
