# CB2-R2b · 工作台场景与烹饪表现精修

基线：PR156，874ed99，20/20 CI；玩家反馈动作更好，椭圆锅气/火焰、灶台原型感、食材栏遮挡。R2b 仅独立料理构筑工坊，保留 R1e 判定、P1配方、经营、存档、正式场景。

## 目标与验收
- 暖色手作奇幻厨房：炉体有砖石/金属框架、火门、把手、木纹和边缘磨损；背景墙、置物架及挂工具构成空间，四厨具有各自备料小景。控制装饰数量，不盖住食材。
- 以非椭圆的连续渐隐烟丝、分层火舌、炭光、汤面波纹、油花/挂汁材质为主；依据现有 f.lit/action/smoke/vent/progress/reduction 等只读状态驱动，不增加实际受热或判定。效果对象一次创建，离场释放。
- 移动工坊舞台、托盘和底部按钮不重叠，按真实托盘高度布局；320/375/390 及短屏，四厨具原动作、离线回退、旧正式渲染保留。视觉目标为可见的整体升级，不以通过测试代替玩家视觉验收。
- 不做正式UI、正式角色/存档、配方/经济调整、R3/CB3迁移。程序化美术先行，若风格仍不足再考虑外部模型和贴图。性能与真机视觉需验收。

## 实装与交接（候选）
- `src/cb2_kitchen_art.js`：暖色墙、砖石挡板、置物架/陶罐/挂件、炉膛/铜边/炉门、木台划痕和灰迹、四厨具专属道具；两种渐隐波动 Shader（烟丝及火舌），炉膛及烤架局部火舌、暖色灯光、炭光、非球体油星/火星、汤面环纹及收汁色、食材粗糙度与刷酱挂汁。非独立工坊不创建新美术对象。仍为程序模型，没有正式贴图/复杂物理/真实流体模拟；蒸汽与熏香用统一烟丝Shader不同参数；实际画质与帧率待玩家验证。
- `three_y4b_research.js`：工坊条件下挂接、隐藏旧球体特效与重复道具、调取景，修正烤串正反面映射，保持模拟和评分不变。
- `cooking_build_workshop.css/js/html`：四行网格（HUD/场景/真实高度托盘/操作栏）、小屏托盘可滚动、缓存 cb2r2b；保留旧操作及离线 2D。
- `scripts/check-cooking-build-workshop.mjs`：原三尺寸及四厨具真实WebGL路径增加舞台/托盘/dock非重叠断言。实跑 V8 对三份改动JS及浏览器脚本语法解析成功；基于实际新模块的 mock 对象运行 29 断言通过（四厨具点火/熄火、离场隐藏、有限位置、Shader文本结构；不是GPU编译）。容器无法访问GitHub（DNS失败），未本地跑Node/Chrome；CI及线上待确认，不冒填。真机截图/玩家验收待。正式存档、经济、评分及配方未改。
- 下一步：先玩家复验本轮灶台与烟火；若不足，按实际截图继续精修，不推进R3/CB3。三主文档已同步候选状态。
