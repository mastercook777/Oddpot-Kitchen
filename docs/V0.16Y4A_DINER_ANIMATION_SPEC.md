# Y4a · 活餐厅：真实营业动作
2026-11-24，基线 5b07eca / PR107。用户同意继续落地。Y3d 肘腕体系迁移至餐厅表现，不更改森林战斗；玩家尚未明确完成Y3d实机视觉验收。
## 目标
从通用摆臂升级为厨具区分的作业、双手端盘、顾客进食与反馈。沿用真实 service actor/订单/厨位；不开新经营循环，不新增菜品、资源、生产速度、订单、碰撞、存档字段。
## 实现
共享 Y3d 两段臂 IK，餐厅厨师工作朝向真实最近的忙碌工位；WOK 锅铲扫炒，POT 长勺搅拌，GRILL 烤夹翻面，STEAM 揭盖/操作；道具仅工作时显示，非工作清理关节及姿态。真实 carried/delivering 双手托盘：盘子在角色身体局部坐标，手部目标由盘沿确定，走路时稳定盘子；根据 plateRecipeId 显示现有菜类可视差异，不生成菜品。普通有手顾客用手部/餐具进食，史莱姆/幽灵保留各自体态反馈；使用真实 eating/review，不假装完成订单。开店前装饰性动作不产生食物，默认待机/走动保持。真实工位蒸汽与食物展示同步；原有 DOM/预警/交互保留。
## 验收
320/375/390：有/无员工、四厨具、跑堂与主角端菜、进食/评价/离席；工作→端盘→空手恢复，餐具不漂浮，手部和盘沿距离；原订单、产出、时间与存档不变；3D失败退回2D。纯函数测试和真实WebGL分开记录。暂不做完整切菜系统（当前无独立切菜状态）、全身IK、全部菜谱专属模型或其他生态。下一步视实机反馈打磨餐厅或推进Y4料理研发场景。
