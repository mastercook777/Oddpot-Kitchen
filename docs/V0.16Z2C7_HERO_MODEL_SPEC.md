# Z2c7 · 主角造型定版工坊（候选，非玩家已验收）
2026-11-26；基线 Z2c6 PR #132 / d5433c3。玩家确认爆裂小队为主参考，先定主角模型，再动画及全角色扩散。
## 目标与范围
以 Hearthcraft 炉火旅厨为原创身份：强剪影、宽脸及颧颊、短而有力的下巴、带偏斜笑意的眉眼、非对称低软厨帽、斜领巾、宽手靴、紧凑冒险夹克/围裙。以大形体为先，配色青绿/陶白/砖红/黄铜；不要复制参考游戏具体角色、资产或商标。身体保留肩肘腕接口与脚底高度，控制头帽高度与原画框。主角性格自信、好奇、可靠，不是婴儿脸或普通制服工人。
本轮不做新战斗动画、员工、怪物或数值；不动存档/2D/经济/生态/游戏整备接入。独立造型工坊使用真实 Z2c5、Z2c6、Z2c7 程序模型，同光线、同尺度、相同相机，可切换前/侧/背/3/4、静态/Idle。无武器时检验角色自身辨识度；武器复核留至正式接入。
## 设计与技术
Z2c7 主要改造脸部连续曲面（方圆颊下颌，眉骨/面颊前向体积）、眼睛斜向外轮廓与粗眉、片状发束、偏心帽冠；衣服用梯形肩胸与收腰、弧边围裙、斜肩带和皮革袖口；增大手靴而不改关节坐标。保留上轮 idle，仅作为可选预览。独立模块，不复制外部模型。工坊不加载游戏存档；一个 WebGL renderer，切换时保持同一光线，页面隐藏暂停。移动尺寸显示清楚。
## 验收
检查正/侧/背/3/4无明显穿插、面部无悬浮零件、整体比例与非对称性、缩小仍可认、不是 generic。无武器亦成立。源码语法、模型接口及工坊静态检查；真实WebGL与移动截图、用户视觉验收和Pages单列。容器此前无GitHub DNS/Blender，程序造型不等于专业雕刻资产。若未达标准优先独立雕刻资产管线，不无限堆几何。只有用户确认造型后才接入实际整备页、再绑定动作并推广；不要求玩家清档。
