# 《怪味食堂》v0.5｜料理驱动的食堂成长（设计草案）

**状态：候选方向，尚未开发和验证；不覆盖 GDD v0.2。**

## 核心循环
新食材 → 研发更高品质的料理 → 在【销售 / 员工餐 / 探索便当】之间作真实食材分配 → 员工与工位成长 → 更好的经营/探索 → 产生下一道料理目标。

## A. 厨房配置
仍保留两个工位。每个位置配置已解锁的 WOK/POT，营业前切换，营业中不可免费重置。对照【双 WOK 火辣快炒】与【WOK+POT 家常均衡】，要求真实改变队列、顾客覆盖、等待与利润。工位 Lv1→Lv2 使用金币，先选 -1 秒或 +1 预制等单一效果；不能凭空生产不匹配锅具的料理。

## B. 两岗位雇员
首先只做一位帮厨、一位跑堂；角色以既有像素小人风格在餐厅活动。雇佣有一次性成本，暂不引入工资、士气、体力、排班与复杂装修。帮厨绑定一个工位提高该处效率，跑堂影响桌位周转/顾客等待风险。
- 每位员工每天最多吃 1 份**真实料理**，从已学标准工艺消耗真实原料；风味与品质影响当晚岗位 Buff（例如辣味菜帮助 WOK、温和汤菜提升特定客人耐心）。
- 可以考虑少量长期喜好/熟练度，但避免无限喂同一道菜成为唯一最优。
- 日报解释雇员实际拯救的等待与订单，而非只给百分比。

## C. 探索便当
依 GDD03 已规划的方向：辛辣料理减轻一次热泉伤害，菌香料理增加一次额外采集机会；消耗一份实际料理与食材，一次出发只能带一份；无便当依然能跑安全线。

## 交互与验收
配置、雇佣/投喂与三菜上架尽量集中在可视化开店准备场景中，避免再变成层层网页菜单；保留三波、两桌、餐厅经营事件和第三日厨王。所有用途共享料理定义与交易账本，不得重复扣料、复盘刷 Buff 或多领销售收入。

**建议顺序**：v0.5A 两个可配置工位 → 同 seed 菜单对照 → v0.5B 两类雇员及投喂 → v0.5C 探索便当与菜谱目标。每一步失败就先调整，不继续堆更多建筑/人员。
