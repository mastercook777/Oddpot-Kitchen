- 将工坊已验收的品质、词缀鉴定、工艺身份、Deck预算与订单快照计算提取为无engine/fixture依赖的共享规则，工坊继续调用同一模块；数值与随机域不变。正式代码可调用共享规则，不复制逻辑。

- 旧根字段与订单不写；新增 cbBuild schema1 status=staged，collection/retired/chapters/backup；以旧全局菜谱与当前两章菜单的完整快照检测过期。当前章安全才允许暂存，休眠章如有未结或未至清晨，标记待审；切章不会丢失全局暂存数据，但不得把候选当生效Deck。重复调用不重新生成；源数据变化报告stale，不自动覆盖。discard只移除未激活暂存，不回滚金币/材料/历史，不允许回滚已激活。暂不在load/newGame/advanceDay自动调用，不在玩家UI开放迁移，不启用新经营/研发行为，避免中途混用新旧规则。后续A2b/A3做真实引擎激活、工艺收藏/Deck/订单/特供/波次/便当与章节规则，完成经济审计后再开放。
