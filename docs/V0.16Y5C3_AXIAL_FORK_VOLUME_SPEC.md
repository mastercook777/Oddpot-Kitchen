# Y5c3 · 烤叉轴向前刺与体积喷流
2026-11-25。基线 Y5c2 / PR116 的17/17 CI通过，但玩家视觉未验收：待机勉强成立，前刺像下劈、火舌像硬贴图。根因：攻击阶段同时插值杆俯仰、身体前倾和手部位移，火焰由二维带状网格组成。
## 动作
保持待机斜握；快速建立水平枪架，收枪/送枪/轴向回收阶段锁定同一杆方向、躯干俯仰与朝向。沿杆轴线移动共同握点中心而非插值两手高度；以双臂共同可达区间限制轴向行程；保持固定.30握距与解剖IK。最后短暂恢复待机。喷焰沿水平枪架，轻微轴向后坐。方向以实际攻击锁定方向为准；不改变即时判定、冷却、数值。测试实际根节点/武器尖端的世界空间位移，不再仅验握点距离。
## 喷焰
去除GRILL旧火舌平面网格路径，使用一个封闭锥形空间代理盒、每像素固定步数射线步进积分三维流动密度/温度，内部白热芯、翻滚的橙红外层、尾部软消散；真实叉尖作为喷口，按锁定地面方向延伸至原技能距离，移动时不改变判定；喷流早期贴合真实叉尖，后续锁定释放点并限制视觉偏移。小型真实空间火星沿流场运动，短暂暖光；不宣称物理流体。限制代理体屏幕面积、步数和单技能一体积，移动端性能待验；保留2D回退。
## 非范围与验收
WOK/POT/STEAM、地图、经济、存档、2D动作与技能规则不改。纯函数检查四方向/轴向位移/固定握距/可达/连续/喷口与范围；WebGL检查实际枪轴、前刺阶段、喷流启用与Shader错误、截图；完整CI及玩家视觉独立验收。Y5d仍后置。
