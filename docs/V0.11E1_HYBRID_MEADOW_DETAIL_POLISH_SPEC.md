# 《怪味食堂》v0.11-E.1 · Hybrid 草地环境精修：丰富而不脏

**状态：已实装于独立分支，待玩家视觉与 iPhone 真机验收（2026-10-14）**
**提案日期：2026-10-14**
**范围：** 独立试验分支 `feat/herb-path-pixel-art-slice`，Draft PR #44。正式 `main` 仍以 `package.json` / `PROJECT_STATE.md` 为准；不得未经玩家同意合并。
**基线：** v0.11-E 已在试验分支完成「温和 Canvas 场景 + 像素厨师、NPC、敌人、食材」混合方案；真实 `drawField` 截图与上一轮 343/343 自动回归均已通过，iPhone 真机仍待验收。**E.1 现已按本规格实施；结果见第 9 节，未合并 main**。
**依据：** [V0.11E_HYBRID_MEADOW_ART.md](V0.11E_HYBRID_MEADOW_ART.md)；[V0.11D_COMPLETE_MEADOW_ART_PLAN.md](V0.11D_COMPLETE_MEADOW_ART_PLAN.md) 仅作已否决的“全像素场景”历史对照；[V0.11B1_EXPANDED_FIELD_SPEC.md](V0.11B1_EXPANDED_FIELD_SPEC.md) 与 [V0.11_PLAYER_FEEDBACK_REBASE.md](V0.11_PLAYER_FEEDBACK_REBASE.md) 规定世界/碰撞/探索关系；按 [FEATURE_SPEC_TEMPLATE.md](FEATURE_SPEC_TEMPLATE.md) 编制。

> **一句话目标**：让草地保持上一轮 Hybrid 的明亮、安静与角色可读性，但通过有组织的光色、草叶组团、路缘侵入、树根/石边细节，获得比当前平底更精致、更自然的“餐厅同源”Canvas 手绘质感；**不通过散布细碎噪点来伪造丰富度**。

## 1. 玩家体验：已有什么、还缺什么

### 1.1 真实反馈和不再争论的方向

- 已确认：角色 / 敌人 / NPC 继续项目统一的程序像素人物规格；草、道路、树、岩石用餐厅式分层 Canvas 形状与柔和颜色。**不恢复地面纯像素 Tile 铺满，也不恢复 B1 粗放的随机圆形/椭圆堆叠**。
- 玩家认可 v0.11-E 比纯像素版舒服；新问题是**地面显得太空、太干净**。
- 最重要的审美标准不是细节数量，而是：第一眼有明确角色/道路/食材，第二眼有可信地貌，放大细看有工笔式局部笔触，手机整体不花、不脏、不抢交互。
- 本轮不改变游戏玩法，因此经营意义是**降低玩家找食材、辨识路口的视觉负担**，不是凭美术增加收益或新玩法。

### 1.2 玩家从入口到采集区的观察顺序

1. **入口**：大片草绿不空洞：有低对比的局部色温变化，细节不干扰厨师和出发方向。
2. **沿路走动**：道路总体清晰，边缘不再像精确等宽管道；草只在少数指定位置侵入边缘、转角有轻微冲刷与压实。
3. **经过树/岩石**：有树根、浅土、落叶、苔痕和相邻草团“扎根”地表的感觉；这些全是纯视觉，不引入无形碰撞。
4. **到达采集点/旅人/敌人**：角色、食材图标和目标框保持最鲜明的局部对比；其周围地表主动退让，无假食材和伪危险标记。
5. **不同随机种子**：同一视觉语言、不同合理布局，不能出现一批精致点缀扎堆挡住真实信息。

## 2. 美术规则与已有系统关系（确认原则 + 提案参数）

### 2.1 四层场景视觉层级（绘制次序）

| 层 | 新版目标 | 允许手段 | 禁止 |
| --- | --- | --- | --- |
| L0 环境基底 | 无缝柔和灰绿大面，兼有温冷和湿干区别 | 保留 E 版 `HYBRID_MEADOW_PALETTE`、线性底色及离屏 `createRadialGradient`，用大片低透明度形体组织视觉 | 每 tile 独立随机点、16px 棋盘纹理、明显条带或高饱和地毯 |
| L1 次级地表 | 稀疏组团草叶、浅色地斑与草流向 | 由**地图级固定种子**生成 2–5 笔聚合的草叶/细刷痕；主要靠近非主交互区 | 单像素胡椒噪点、每帧 `Math.random`、密铺花纹 |
| L2 路缘 / 物件着地 | 路缘草侵入、树根/石边浅土、苔与落叶 | 沿现有真实 BFS `plan.trail`、`f.obstacles` 安排局部低对比组团 | 侵入道路通行判定、覆盖危险预警圈、误导为可采集物 |
| L3 角色与互动 | 像素厨师、敌人、NPC、食材、任务标记始终醒目 | 沿用 `src/pixels_v041.js` / `drawHerbPixelNode` / `drawHerbPixelEnemy`，原血条和敌人预警 | 重画成平滑 Canvas 人物、降低交互框对比、物件穿帮、重复绘制 |

**已确认的标准**：L0/L1/L2 应作为安静的环境；L3 是主角。**各类具体密度和对比数值以下均为待实现试验建议**，不代表玩家已确认最终阈值。

### 2.2 地表：有组织的宏观变化 + 少量微观纹理

- **宏观区域变化**：保留现有 `hybridMeadowGroundInto` 的 12×16 连续地面与 E 版约 11 处柔和阴影/高光池，不增加整屏高频亮点。把现有色差按「暖阳地、湿润草、树下微阴」组织成连贯大块，而不是无意义随机色云。色差须低于食材轮廓/目标标记，不能出现粗黑外描边。
- **微观草感**：新增非重复的 **三类手绘样式**：①2–4 根短草叶弯笔，②浅深各一笔的低对比刷痕，③极小的草花/落叶组团（仅少数）。每组集中成一块，尺寸建议 0.18–0.5 世界格，禁止“多个独立彩点”。
- **分布预算（提案，可调）**：整张 12×16 地图环境细节 **约 18–26 组（建议初始 22）**，其中草地自由组团 6–9、路缘 6–8、树根/石边 4–7、少量特色点缀 0–2；不能将四类独立预算相加超过总预算。允许某种地图有更少细节，绝不为了凑满配额硬塞装饰。
- **可读性退让**：出生点半径建议 `1.5` 格、可采集节点/旅人半径 `1.15` 格、敌人常驻预警区域（依实际半径）尽量不加入有辨识度的装饰；土路**中心轴保持畅净**，优先把装饰放在路外侧。装饰只影响视觉，不改变节点/敌人位置或拾取判定。
- **对比控制**：草笔颜色优先复用现有灰绿家族（`grass`、`grassLight`、`grassShade`、`moss`）；个别暖黄用于树下枯叶，但强金/红/白保留给互动、危险或受击。低对比透明度候选 0.12–0.30，实际以手机截图为准；**不把数字当绝对美术质量标准**。

### 2.3 道路：自然边缘但保持识路

现有 `hybridMeadowTrail` 从真实 `herbPixelGroundPlan(f).trail` 生成连通骨架。**继续用同一可通行骨架，不能修改地图寻路**。

- 保留 E 版已缩窄的 4 层土路色带 + 微弯曲；在**外侧轮廓**局部做少量宽窄变化（建议中心路宽变化不超过当前宽度的 ±8%，不靠真正改通路宽度形成所谓“随机坑”）。
- 在确定性的若干路缘位置加入 **草尖侵入、断续泥土刷痕、低对比浅石/踩踏色差**，从远看路仍是一条完整路径。
- 十字路口/转角只放 1–2 个细节锚点；直线段间隔放置，禁止每格都配一个相同小花/草簇。接缝和交叉路口不能显露圆头反复盖章的“香肠链”。
- 不画连接阻挡格的假路，不在节点上绘制与可采集图标相似的高亮物件。视觉路面可落在可走网格内及紧贴边缘，但**不等于真实碰撞范围**。

### 2.4 树木、岩石与着地微环境

- **树**：保留 E 的分层、带树叶受光面的叶团与有木纹的树干，仅在根部增加低透明泥土色斑、两侧向外展开的少量根须/草簇、2–3 片成组落叶。可复用 `hybridMeadowTree` 的既有 3 种冠型变化，但避免每棵树叶片一样排布。
- **岩石**：保持明确的阴影与切面，只有局部苔绿和侧缘稀草；避免满石头噪点。底部阴影和地表色差要协调，不能让岩石悬浮。
- **绘制分层**：根部底纹属于 L2 地面，应在角色下方绘制；树冠仍沿现有世界 y 轴先后层遮挡角色。必要时把“根部环境”与“树冠主体”分为不同函数，以免放置大树时整株硬遮角色。
- **实体唯一性**：只画源于现有 `f.obstacles` 的树石，不能额外制造看上去能阻挡却不可碰撞的大石/树干。纯装饰不得成为同色的假食材。

## 3. UI、移动端与奇幻表现

- 不新增地图按钮、提示浮窗、名字牌、任务提示层。主角、NPC、敌人、食材、危险裂隙、摇杆/HUD 均继承 v0.11-E 的行为与触控。
- 探索第一段 `biome.zoneId==='herb_path'` 且 `worldVersion==='0.11-B1'` 启用；其它七生态、旧 9×11 存档、餐馆 Canvas 均走原实现。
- **验收视口**：先截 430×932 Chrome 同种子对比，再检查 390×844、375×667、320×568（小屏优先），真实 iPhone Safari/触控必须单独试玩。镜头移动不应产生“路面跟随滚动时纹理闪烁”的观感。
- 配色仍以 E 版现有柔和灰绿、土黄为基线；不回到原来像素噪点色板。奇幻氛围由角色、奇特食材、轻环境造型体现，不靠更多 UI 文本。

## 5. 最小可玩范围与分期

- **P0 必须**：草地宏观色差可感、低密度草簇组团、道路边缘细化、树根/石边接地细节、固定预算/排斥区域、缓存与不改模拟、同镜头 E/E.1 对照。
- **P1 视初版截图决定**：3 种以上草笔的形态与极少落叶/野花，在不加污染前提下调色、疏密及道路粗细；不同光照种子视觉差异。
- **延后**：其它七种生态的同风格铺设、更多敌人/商人/新料理、新美术音效、独立图包量产。
- **明确不做**：新地形碰撞、自动采集触发范围改变、单局路线改难、角色从像素改 Canvas、任何经济收益/存档规则调整。

## 6. 参数建议与区分

**已由用户确认**：美术混合方向、保留像素人物、草地精致但不能脏、道路更自然、树根/岩石附近补细节、只精修香草小径、先设计文档再开发。

**尚未通过用户视觉验收的首轮建议参数**：

| 指标 | 首轮建议 | 验证方法 |
| --- | --- | --- |
| 地图细节组团上限 | 18–26，初始 22 | 真实 12×16 地图、多 seed 统计 + 截图 |
| 自由草地组团 | 6–9 | 占位避让，缩小图不形成噪点 |
| 道路边缘组团 | 6–8 | 入口/路口/近交互区域截图 |
| 树石根部组团 | 4–7 | 实体树石比例；不得悬浮或遮路 |
| 特殊小点缀 | 0–2 | 不与食材/危险标识混淆 |
| 互动资源避让半径 | 候选 1.15 世界格 | 近食材目标框清晰，无假资源 |
| 出生点避让半径 | 候选 1.5 世界格 | 入口图与触控无遮挡 |
| 土路宽度微变化 | 相对 E 当前宽度 ±8% 以内 | 连通、分叉清晰且无“软管感” |
| 静态纹理透明度 | 大致 0.12–0.30 | 以实际视觉对比度与 iPhone 截图为准 |
| 性能预算 | 单张地表图缓存，避免新增每帧大循环 | Web Inspector / GitHub 构建与 Safari 真机 |

参数不是定稿美术规范。如第一版视觉仍偏空，应先优化**组团位置和形态**，不先把密度上限加倍。

## 7. 验收与风险

### 7.1 功能 / 自动化验收（Codex 可实施）

- **AT-E1-01**：在相同种子/路线与玩家位置下，E 与 E.1 的 `f`、`nodes`、`obstacles`、`hazards`、`spawn`、背包和可获得奖励序列完全一致；画面纯表现。
- **AT-E1-02**：至少 64 个种子，所有装饰点在地图内、数量不越预算；路缘不生成额外路径节点，现有可达性与避险 `fieldTilePath` 仍正确；保证相同种子重复运行生成相同组团。
- **AT-E1-03**：采集、NPC、出生区排斥规则生效；树根/岩石底纹不画额外实体，不与节点标记及敌人预警圈竞争。
- **AT-E1-04**：混合环境继续保持平滑 Canvas，`pixelActor`、`pixelEnemy`、`drawHerbPixelNode` 仍被使用；非 `herb_path` 生态/旧 9×11 存档完全走旧渲染。
- **AT-E1-05**：重复 `drawHybridMeadowGround` 复用缓存，不在同一 `f` 下逐帧创建 Canvas/布局；离线 bundle 与 module 一致，`npm test`、`npm run build` 与 Playable CI 全绿。
- **AT-E1-06**：同种子 `20261013` 的截图至少包含入口、道路中段、树石近景、采集点，另取至少两个不同种子防止样板过拟合；建议同时输出 430×932、390×844、320×568，文件路径/标签不能将 E0 误写成 E1。
- **AT-E1-07**：原来三种画面回退模式保留；可在实验分支切回旧 E 场景与 Pixel 做对照，不改用户存档，也不自动合入 `main`。

### 7.2 人工视觉验收（不得由 CI 替代）

在**正常手机浏览尺寸**、而非只放大素材，逐项确认：
①地面比 E **丰富**；②不出现像素雪花/随机撒点感；③路口一眼可认且不再像直角塑料管；④树下有着地感；⑤像素厨师、敌人、食材是画面最鲜明的信息；⑥连续移动无纹理闪烁/掉帧；⑦ iPhone Safari 摇杆、触控与前景遮挡正常。

若发生冲突，**先删最抢眼的细节**、再调低对比与聚簇位置，不通过覆盖游戏 HUD 或降低人物轮廓对比来解决。

### 7.3 风险 / 回退

- **风险 A：重新变脏**。诱因是均匀点撒与贴近互动物。回退低频自然草笔并严格执行预算、排斥半径。
- **风险 B：反而更花、更难识路**。道路边缘效果只作色彩/笔触，中心骨架仍明确；不要加与拾取目标相同的黄白高亮。
- **风险 C：对象看似可碰撞/可采集但实际不能**。只在现有 `f.obstacles` 根部添加对象细节；松散草/叶不得成为醒目的实体。
- **风险 D：移动端性能**。新增笔触只静态画进 `hybridMeadowGroundCache` 的离屏图，若首次进入卡顿，降低绘制复杂度，不在每帧缓存。
- **回退策略**：保留 v0.11-E 既有场景 renderer 可在 Draft 预览中一键切换；若 E.1 观感不佳可恢复 E，而非回到粗糙 B1/全像素，`main` 无任何回退成本。
