## 1 玩家体验
清晨门口是一枚有实体层次、清晰主操作的紧凑旅行路牌，借鉴手游主操作的层级、按压反馈而非复制 Supercell 资产；保留真实门槛投影。外出先看一个地区的动态生态样本，可切地区；场景展示当前地区实际可能出现的怪物，非固定遭遇承诺。下方两张紧凑路线牌，用真实路线名称、产物、风险描述，直接进入对应路线。主角正面 idle 预览与右侧小型装备选择器，点击立刻在真实持握模型上切换；仅展示玩家拥有且当前可用的厨具及真实精通等级。
## 2 规则与系统
复用地区/路线原 id 与 enterField、fieldWeaponChoices/selectedFieldWeaponType/selectFieldWeapon、真实 ECOLOGY_ENCOUNTERS 及 biome。地区预览从两类入口 biome 的真实怪物集合取样，采集并非无敌人，狩猎并非另一个地区。升级使用实际 mastery Lv1/Lv2，不提供凭空选择等级。共享战斗武器 rig 增加 Lv2 可见模型部件，2D 原有等级绘制保留；不改攻击、命中、姿势运动学、数值、经济、存档。
## 3 UI
固定预览容器尺寸与画幅，不因 2D/3D active 或选中态改变；渲染后保留画布/首帧，避免闪动；地图内只放区域标记/生态，路线移至独立紧凑双卡。主角在左，装备在右，按需看参数；小屏纵向可滚动，触控目标44px。清晨出发按钮保持门槛定位且按压不拉伸场景。
