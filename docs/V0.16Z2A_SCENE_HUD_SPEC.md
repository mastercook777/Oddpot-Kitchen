## 改造
- 仅真实走动营业及探索行动采用新布局：单行边缘HUD（营业波次、上菜、精力、账册、暂停；探索生命、背包、段次/秒、设置），取消大品牌、阶段条及重复状态。保留 firstDayGuide 确认/跳过，紧凑显示，仅首次。金币/声望/日数/等位/任务/缺料与详细订单进入营业账册；探索原设置可达。订单状态用真实 o.status / sat / patience；现有文字台词数据保留，账册中显示实际当前对白，不生成虚拟订单。原设置入口在账册中可打开；暂停仍一键。账册使用现有overlay，打开期间原时钟暂停条件不变，关闭继续。缺料警告不消失，压缩到边缘，完整原因账册可看。
- 营业引导底边紧凑，仅取餐/上菜保留对象与进度，烹饪状态短指示，首次指引仍在；3D真实目的地标记保留，去掉重复目的地文字，2D正常动作提示。3D与2D活动食客头顶统一小型符号/颜色（等待、点餐、烹饪、待上菜、进食、评价、离开），着急用!，好坏用✓/!，不画每个菜名与常驻对白卡；最多一条高信号台词可在账册查阅，主场景不再显示大卡。员工头顶只保留必要进度/符号。非营业清晨对白不改；旧非walkable服务保留。
- 探索HUD移到单条顶部；盾/便当状态在窄小的边缘辅助标记；保留原技能、背包、完成段落与撤离（本轮不改原直接撤离规则，确认机制后置）。底部短操作栏，高度44px+安全区，去掉长常驻指令，首次指引仍可访问。技能44px以上，触摸区域、摇杆、双指与Z1a兼容；不改战斗、路径、镜头、生成、库存、订单、存档、核心版本、3D恢复及云港2D。
- UI tokens 深墨绿/暖金/浅米，统一按钮与状态符号；不把视觉重构当纯CSS，实际改结构及Canvas文字绘制。只做当前两种行动场景，其余阶段Z2b/c。
