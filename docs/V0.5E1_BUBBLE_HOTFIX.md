# v0.5E.1｜顾客对话气泡定位热修

本轮**仅调整 Canvas 气泡表现，不改变点单、料理、雇员、存档、经济、评分、订单与营业事件规则**。

## 修复的问题
- 原逻辑把第二个座位气泡额外上移 28px；对话与人物头部脱离，甚至移到厨房区域。
- 每个人独立绘制气泡，左右双人会在同一位置重叠，屏幕边缘容易裁切。
- 长评论按单行强行挤在气泡里，阅读困难。

## 新行为
- 统一以 `guestStagePosition` 的实际人物坐标 `pos.y - 22` 为气泡尾巴的头部锚点，跟随走路和入座。
- `dinerBubbleLayout` 在同一帧为可见的所有对白做避让：优先靠近头顶、按座位向外展开、左右边缘最少预留 8px。
- 双人桌两位同时说话时尽量保持同一高度，不再通过无条件的 28px 高差避开。
- 长评价最多分两行，过程性“看菜单”等次要气泡在更多重要评价出现时退让，重点突出点菜和好评/差评。
- 对话三角尾端指向真实人物头顶；无气泡的用餐动作和顾客耐心环不变。

## 验证
- 既有 92 项规则测试 + 新增 6 项布局测试（总计 98）。
- Headless Chromium 320×568、375×667、390×844 模拟实际 Canvas 渲染、无 JS error、无整页横向滚动。
- 真实 iPhone Safari 上的字体渲染、多人同时讲话的舒适程度，仍需玩家回归体验。
