# 《怪味食堂》v0.5A · 厨房配置与永久升级（可玩验证）

状态：2026-10-10 · 已实现，**尚未经过真实 iPhone Safari 玩家验收**。以 GDD v0.2 + GDD02 现有营业规则为基础，提前将 GDD02 §13 的设备成长压缩为可操作的两个厨位原型。

## 玩家目标

一道菜能否卖得好，不仅取决于风味和品质，也取决于餐厅是不是为这套菜单准备了正确的生产能力。玩家应该能够观察到：“双炒锅让两道炒菜同一时间出锅；但当晚没炖锅，蘑菇焖鸡就不能上架营业。”

## v0.5A 的明确实现边界

1. 保留物理上左、右两个厨房位置，各自可配置 `WOK`（炒锅）或 `POT`（炖锅）。支持 WOK+POT、WOK+WOK、POT+POT、POT+WOK。
2. 开业前的备餐场景内点击锅位即可换锅；同一天第一次免费，后续每次 12 金币，真实扣款并写入共享交易账本。配置长期保留，但下一天仍允许重新排布。
3. **强制兼容菜单**：三道已上架菜需要的锅具类型必须都能在这两口厨位找到。否则“开门迎客”按钮不可用，明确指出缺少的锅具，避免凭空出餐。如果玩家换错锅且余额不够恢复正确配置，允许一次必要的免费纠错，防止软锁。
4. 厨位 Lv1→Lv2 的永久升级在日结成长页购买，左厨位 60 金币，右厨位 75 金币；各工位制作每单 -2 秒，等级保留，换锅不会重置等级。旧存档的原炒锅改装迁移为左厨位 Lv2。
5. 厨房调度现在以物理厨位分别执行，双炒锅可以并行炒菜。原先服务订单和队列、顾客偏好、原料真实扣除、事件、波次、利润、三日挑战仍然是权威系统。
6. 在营业画面绘制对应的两口锅及等级，在日报展示每个厨位的接单数与累计节约秒数。
7. 保留 v0.4 存档键与 schema `version:4` 并在读档时迁移 `kitchen` 字段，避免 v0.4.5 玩家丢失进度。

## 核心验收

- 同一个场景里两张未开始的炒菜订单，WOK+POT 只启动一口锅；WOK+WOK 可以两口同时制作。
- 配置双 WOK 却在菜单保留 POT 菜时，不能开店；调整为 WOK+POT 后恢复开店。
- 每日第一次改锅免费，后续扣款不可重复入账；余额为 0 且误设不匹配时有免费恢复路径。
- 厨位永久升级后真实减少时间且不能重复购买；成本结算原规则不变。
- UI 在 390×844、375×667、320×568 下可点击双厨位、三道备餐和开业；无整页滚动，小游戏画面仍为固定视口。
- 旧版三日收益、挑战结算、探索采集与研发测试不得退化。
