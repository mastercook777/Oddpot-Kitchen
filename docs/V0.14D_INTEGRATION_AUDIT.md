## 经济与客户决策

新菜原料估值 4–12、基础售价 23–39、基础时间 9–13 秒。统一质量 85 的基础工艺售价对应 28–44 金币（刷香另走招牌工艺加价/加时），并非“换名同价”。选择测试是已排定的真实客户，且菜单中同时有鸡汤；80 种子中四类客群会主动选择烤串。另一个混合菜单里高品质炭火椒牛串可能败给更便宜、同样满适配的旧辣肉菜；这反映预算/口味竞争，应通过长期经济数据和玩家体验决定后续调价，不能给烤架人工保底单。

本期不增“烧烤狂热客”：六类现有客人已有实际口味/订单/对白需求。独立新客至少需到店节奏、头像像素人物、可读对白、熟客关系与预算差异；若后续新增章节有足够独特行为再做。

## 仍未串联/后续

1. 烤架仍无与炒锅/炖锅对等的付费厨具升级；作为购买后基础版保持原规则，不悄悄改变经营数值。应先量化第三工位、原料供给和升级收益。
2. 探索便当只接受已有 `RECIPE_PROFILES` 的特定菜，新增烤串不会自动成为便当；本轮无相应探险能力设计，不能仅加 UI 假入口。
3. 多日真实探索获得量→轮换采购→十道菜混合菜单利润、二星成本回收尚未完成专项量化；不能将单夜选菜视为完整经济验收。
4. 强制首轮引导由玩家明确暂缓。第三星/传送门/异界独立章节不属于本轮。
5. CI 无完整中文字库；矩形烤架、火焰层次及 320/375/390 屏截图需人工复核，最后仍请玩家用 iPhone/Android 试玩确认。
