## 已实现基线与待验证假设

- 新 run 的 NPC 机会为安全 40%、危险 50%，独立生态事件 25%；连续两次完整 run 没生成 NPC 机会后，下次安排一次。**机会不等于玩家一定发现或交易**，早撤不增加未遇次数。每完整三段最多一位交易 NPC。
- 商人 36 金币换逆潮酸浆×2；旅人按地区用普通材料×2换星露花蜜×2。材料先入野外包，撤离才入库；晕倒按既有减损，金币不自动退。两份的初衷是一份研发、一份用于经营，实际盈利与发现频率尚待验证。
- 两份材料接四道 rare 菜、原隐藏菜单资格和 1–2 份限量；真实订单成交才算收入。不能以菜谱标价直接代替实际销量或净利润。
- H 的四种受击参数为首轮手感值；Chrome 双指通过不等于 iPhone 触控、主观打击感和帧率验收。B2 新怪群节奏、C 新奇遇经济也仍待玩家反馈。

## 验证口径和边界

同一批种子固定初始金币、装备/锅具、便当与已研发状态，分别记录路线、三段时间、受伤、采集、事件是否生成/可达/被主动发现、交易成本、袋位、撤离损失、研究后剩余材料、菜品真实订单利润。额外复核低金币、满包交换腾格、事件拒绝、途中保存/重载、旧 run 不重抽、重复点击与重复日结。建议结果用中位数、范围和逐局案例呈现，避免少数幸运局决定全局参数。

不新增货币、敌人血量、地图大区、清场门槛或平行结算；维持 `oddpot-prototype-v04` / schema 4、唯一 `eventId` 交易、原撤离及订单账本。视觉/操作修正沿用像素角色和 Hybrid 场景，不引入常驻浮窗。任何改价、概率或掉落前都要在此记录真实触发问题与对照结果。
