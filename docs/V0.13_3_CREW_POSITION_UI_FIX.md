- 员工面板说明文字和设置后的反馈只解释优先站位及自动支援。营业期间原有跨炉动态补位仍照旧：需要真实订单、实际移动时间、到位后才计入产能，且不打断在烹订单。
- 补充禁选按钮的视觉弱化，保留触控高度、已选高亮与 `aria-pressed`；完整三厨位移动页面、小屏和离线包沿用原有布局。
