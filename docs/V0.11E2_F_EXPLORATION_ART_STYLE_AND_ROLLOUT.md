## 1. 玩家体验与定版范围

玩家能够在草甸、菌沼、古树、菜圃与热泉各生态连续取材，场景细致但安静；人物、可采资源和危险依然一眼可认。炒锅挥击、深锅投射、敌人攻击、命中、采集和环境反馈采用同一种平滑绘制语言，避免精细场景中突然出现方块弹道、像素爆炸或十字闪光。

本阶段继续以取材服务料理与经营：降低找资源、读危险和辨别路线的负担。重绘不提高战斗难度、不改可得食材数量，不以新特效伪造伤害、奖励或成长。

### 1.1 表现对象与边界

| 对象 | 确认方向 | 说明 |
| --- | --- | --- |
| 厨师、NPC、普通敌人的本体 | 保留统一像素精灵 | 保留现有尺度、轮廓、行走与动作；不借特效改角色造型 |
| 可采食材、真实掉落本体 | 保留像素食材 | 实际食物仍可认；采集光效与掉落反馈为非像素 |
| 草地、水面、道路、树根、岩石、菌柱、晶体 | 精细卡通 Canvas | 延续 E.1 柔和色块、局部细节和接地感，按生态重新设计形态 |
| 攻击、弹道、爆炸、命中、格挡、采集、环境动效 | 非像素 Canvas | 用曲线、连续形状、渐变与少量圆润粒子；不以 emoji 充当爆炸动画 |
| 目标框、旅人提示、预警与进度反馈 | 平滑 Canvas 图形 + 可读文字 | 像素食材外面的四角框、星芒、蓄力标记也纳入统一；不增加永久浮窗 |
| 生命条、伤害/获得数量文字、HUD | 简洁连续图形与普通字体 | 信息不需要像素化；数字来自真实状态 |

**当前事实补充：** `monster()` 中两个 Boss 本体仍有旧 Canvas 占位造型，不能声称现有全部敌人都已是像素精灵。本轮不新增 Boss 本体重制；其现有预警、弹幕、受击和死亡特效纳入 E.2，后续本体资产任务须遵守上述角色规范。

**禁止遗漏：** 特效统一不能只删矩形挥击；方块投射、两个 pixelImpact 入口、NPC spark、目标括角、emoji 爆炸和头顶蓄力标记都须逐项审查。全像素历史对照模式可以保留旧表现，正式 Hybrid 路径不再调用像素特效。

### 2.2 绘制语言

- 用连续的圆弧、贝塞尔曲线、圆润弹体和柔和有限渐变；形体先行，发光从属。避免巨型白闪、四处撒彩粒和统一大爆炸盖住人物。
- 共享线宽、亮边、消退曲线和色彩家族。玩家动作偏暖奶油/柔金；实际受伤偏珊瑚；孢子偏冷紫青；热泉偏青白；危险预警仍需高对比。具体配色/强度为首版待视觉验证参数。
- 提示层级：**危险时机与范围 > 玩家/敌人攻击与命中 > 采集/NPC交互 > 环境氛围**。危险与安全水面不仅靠颜色区分，兼有裂口/岸线/预警形状。
- 普通攻击与强化技能通过范围表现、节奏和亮度区分；视觉不能让玩家误判实际命中范围。装饰光晕可略超出碰撞形体，但不能用实心攻击形状暗示不存在的伤害区。
- 非像素特效与像素实体逐层隔离：独立 save/restore；特效用平滑路径，实体贴图保持 imageSmoothingEnabled=false。不能把整张场景或角色精灵一起模糊。

### 2.3 与模拟的契约

继续读取 `attackFx / playerProjectiles / projectiles / skillFx / guardTime / shieldFlash / hurtFx / hitFlash / strikeFx / warning / deathFx / harvestProgress / popFx` 与 `hazardPhase`。

- 保留现有伤害、命中方向、锁定 aim、前摇、冷却、盾次数、半径、生命和背包结算。采集仍使用原 0.82 秒；预警圈读原 hazard.radius；不能为“看起来更爽”延长 invulnerability 或增加伤害。
- 抛物线使用现有弹道进度，落点使用原 targetX/targetY；实际结算时只触发一次表现。
- 若需要替代「💥」的明确效果类型，可在临时 popFx 中添加只读表现字段；不扩写持久存档、不增加第二个结算时钟、不用“比较血量变化”重复触发命中反馈。玩法数据相同验证可排除纯表现字段。
- 动画按原模拟时间绘制；暂停即冻结。环境纹理固定地图 seed；不调用每帧无种子随机、不触发掉落/收入。

合计 **两大区、八生态母版、十四个当前 zoneId**。包含安全/风险路线、秘密支路与首领入口；本轮不新增地理区域。最终清单应按 `field_biomes_v081.js` 的 ZONES 逐项核对，新增 alias 也应映射到其母版，不能仅重绘首段。

### 3.1 共用四层规范

1. **L0 基底**：连续低频光色和生态地面大块，不按 tile 撒细点；水/土/岩有各自结构。
2. **L1 地表细节**：固定 seed 的局部组团，依湿岸/树下/岩边组织，而非均匀贴花。
3. **L2 物件接地与景深**：真实障碍才有大树/岩柱/晶体；阴影、根部、苔痕与岸缘先铺地面，主体按世界纵向排序。地形美化不增删障碍。
4. **L3 像素实体与非像素反馈**：角色、资源清晰，特效连续；环境最安静，交互优先。

静态图缓存、细节上限与出生/节点/陷阱/敌人区退让沿用 E.1 思路。E.1 每图上限22组、出生1.5格、资源1.15格是已实现基准，其他生态可在首批截图后调整，不能机械复制草叶形态或默认加倍密度。水面、热流等动态层与静态缓存分开，避免每帧重建整张地图。

道路仍来自真实可通行路径。草甸可用土路，菌沼可用干地，热泉可用岸线，危险区可用断岩间的自然通路；不能画一个连接阻挡格或必经陷阱的假安全路径。装饰水面可通行时不画成看似完全封闭的悬崖/深渊，真实危险只由原判定驱动。

## 6. 数值与性能建议

- 已确认的是绘制语言、范围和顺序；粒子数量、光强、线宽和淡出形态属于待首轮验证参数。
- 保留现有模拟反馈时长为时间基线，不修改 ttl/冷却去配合特效。表现插值可以改变，伤害事件不改。
- 提议普通瞬时命中3–6笔/粒、强化技能6–10笔/粒；环境可见运动组团4–8组，密度低于战斗。先提高形态质量，不以粒子数量证明升级。
- 提议可见瞬时效果并发上限24，环境上限8；只削减装饰尾迹/余辉，不削减真实弹体、攻击预警、落点或反馈文本。具体阈值在第一版性能记录后回写。
- 不使用整屏持续重滤镜和反复 shadowBlur；静态环境沿用单场景离屏缓存。至少记录主屏尺寸/DPR、平均与较慢帧耗时、地图首次生成和镜头移动情况；不虚构未测试设备的 FPS。

## 7. 验收

### 自动/工程

- **AT-FX-01**：相同 seed、地图、输入序列下，新旧表现的生命、命中、攻击目标/时机、伤害、掉落、采集、背包、金币和结算一致；仅临时表现字段可不同。重复绘制不变更玩法状态。
