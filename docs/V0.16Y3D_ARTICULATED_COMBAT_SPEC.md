# Y3d · 炒锅攻击与自然持握专项
2026-11-24，基线 1a6d625 / PR106。玩家认可汤锅攻击暂可，锅铲/汤勺持握呆板，WOK攻击像盾撞。源码仅肩单关节，厨具随整条臂转动，躯干前倾与盾抢戏。
## 参考与原则
Moonlighter 剑盾职责（https://moonlighter.fandom.com/wiki/Swords_and_Shields）；GDQuest 快速攻击的 anticipation/smear/easing（https://www.gdquest.com/library/juicy_attack/）；Game Developer 响应与 follow-through（https://www.gamedeveloper.com/production/the-12-principles-of-animation-in-video-games）；Death's Door 动作节奏（https://www.gamespot.com/reviews/deaths-door-review-a-murder-of-crows/1900-6417699/）。仅参考设计方法，不复用素材。原模拟在 attackFx 产生时已命中，视觉不能延迟判定。
## 实现
Y2b 主厨增加肘、腕层级，原餐厅模型及默认姿态保持；森林 WOK 用两段臂解析 IK，手腕独立指向锅铲尖端。待机锅铲斜下外侧、自然屈肘，盾侧低持；移动有轻微摆动；攻击命中帧锅铲在目标扇区，快速横向随动与回收，盾保持相对稳定，仅 guard/shieldFlash 举盾；身体扭转不过度前冲。真实武器世界轨迹驱动原生3D残影，替代固定WOK弧（故障回退）；POT待机自然屈肘、勺斜持，现有抛射攻击姿态/弹道/时长保持，GRILL/STEAM不重做。
## 验收
手臂长度恒定、腕方向、四向、锅铲接触和盾位、攻击恢复、只读与回退；新增纯函数测试及真实Three.js构造/世界位置验证（环境允许时），手机实测另记。无数值、AI、掉落、地图、存档、经济变更。暂不做新武器或全身骨骼动画。
