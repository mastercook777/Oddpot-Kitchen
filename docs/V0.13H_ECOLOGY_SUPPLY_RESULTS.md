# v0.13-H · 生态采集 / 狩猎路线真实生成器产出审计

**日期**：2026-10-15 · **版本**：v0.13.0-alpha.7（PR #68 已合并 main；475/475 Node 和 12/12 GitHub Actions 通过，Pages和iPhone真机另计）

## 前置经济问题

v0.13-G 连续21日三炉固定菜单仅靠当日4款轮换市场时，几乎每日缺料；外生每天8份有效菜单材料的敏感性实验使平均日销量5.79→8.27，但不是一次真实野外探索净利润。故本版要给探索明确且能被地图生态预示的**食材供应差异**，而不是任意指定材料后的必得2份。

## 统计方法与边界

- [可执行脚本](../scripts/audit-ecology-supply-v013h.mjs)复用真 `newGame/enterField/chooseFieldBranch/generateBiomeMap/startActionField/addFieldBag`：**80个seed × 4种入口路线 × 二次分支各2种 = 1,280个连续三段地图生成样本**；旧版基线采用同组样本。
- 「静态采集点潜力」来自地图真 `f.nodes` 数量，包含部分受怪守卫的采集点；不等于无需战斗全带走；每张地图按实际生态权重从多种材料产生，首段不再由`selectedTarget`强塞任意2份材料。
- 「敌人掉落潜力」来自真 `startActionField` 生成的普通敌人种类（鸡→鸡肉、野牛→牛肉、菌怪→蘑菇、蒸汽蟹→土豆、火椒怪→火椒）。**仅假设把所有普通敌人打死才有机会采到这些物品**，并未杀敌、采集、模拟HP、判定是否被敌人击倒；其展示严格作为资源潜力，不是实际通关所得。Boss和NPC独立结算及稀有货不算入普通材料统计。
- 背包通过正式8格、每格最多3份的`addFieldBag`测试「采集优先」与「假设全杀敌后追加掉落」两种容量上限，不给永久仓库直接发货、不绕过唯一入库结算。
- 怪物强度、生态可视性和实际路线成功率需手动iPhone试玩并据此校正；不能声称「猎杀潜力」都是可得收益。

## 同种子旧路径 vs 新路径

| 入口 | 历史静态采集潜力 | 现行静态采集潜力 | 历史普通敌人潜在掉落 | 现行普通敌人潜在掉落 |
|---|---:|---:|---:|---:|
| 森林采集（内部safe） | 15.38 | **17.58** | 13.30 | **10.75** |
| 森林狩猎（内部risk） | 13.94 | **13.34** | 17.65 | **18.22** |
| 热泉采集（内部spring_safe） | 15.33 | **17.82** | 13.25 | **10.49** |
| 热泉狩猎（内部spring_risk） | 13.89 | **13.39** | 17.36 | **17.85** |

新路径森林采集静态蔬菜/菌蒜的潜在数量均值16.85，森林狩猎仅11.47；普通敌人“鸡/野牛肉类掉落潜力”森林采集8.32，狩猎**12.52**。热泉采集土豆/蒜瓣/洋葱等静态非火椒植物潜力11.40，而热泉狩猎3.36；热泉狩猎静态火椒潜力8.44，对应热泉采集5.80；加上怪物掉落热泉狩猎更多战斗相关火椒/土豆收益。

**平衡解释**：即使玩家击败所有敌人，狩猎总潜力可能更大；但未必能全部拾取、还存在HP/额外移动/时间风险，且采集路线的专门蔬菜、根茎供给通常更强。这是两个不同结构的资源路线，不是按“危险较高→必然赚最多”设计。后续一定需要实际玩家通关率、用时和带回仓库组合校准，不应把潜力数字当实际可回收资源。

## 地图数量修正与真实机制

- 每次仍是**真实游玩3张地图**：首段×1 → 下一段2选1 → 第三段2选1。
- **8种视觉生态，14个既有zoneId全部通过真实入口/分支组合可抵达**（新增了以前不可抵达的`forest_secret`与`spring_market`），相邻两段不再使用重复区ID或相同生态；两次分支真正落地不同食材集中点。
- 森林采集依地图选菜圃/菌沼；狩猎经古树兽巢→野牛觅食草场/孢怪沼→菌王终点。热泉采集选择晶池/蒸汽裂隙后深层采集或Boss；热泉狩猎从赤焰野兽区域→蒸汽猎径/蟹群浅滩→熔岩Boss终局。两个Boss入口生态也有不同肉类/野生怪资源权重。
- **彻底取消出发前“目标食材”选择器和事件处理**。仓库菜单缺料仅以“少于6份”作只读参考，不修改随机种子或掉落。新地图的 mandatory `key:'target'` 定义为“本区通关采集点”，其`id`来自`getFieldBiome(zone).primary`而非存档旧 `selectedTarget` / 路线分支人为指定；提示只能说“本区采集完成”，不会把旧的“今日目标”带回。
- 老 schema4 在途 `field` 没有 `targetMode:'ecology'` 时，原路线/目标完成语义原样延续；新游戏无须升级存档结构版本。每次正式入库仍只由`settleField`交易触发一次。稀有材料Boss/NPC特殊获取保留。
- 不是14张手绘独立图：十四位置仍按原8类生态Canvas风格复用，并由seed调节采集、障碍/敌人/地形。重点是资源/行为路线真正有区别。
