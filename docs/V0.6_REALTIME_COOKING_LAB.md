# 《怪味食堂》v0.6 · 连续实时料理实验室（独立试验，不替换主线）

状态：2026-10-11 · 首个可交互 H5 试验版。**实验 URL：** https://mastercook777.github.io/Oddpot-Kitchen/experiments/v06-realtime-cooking.html

## 要验证的问题
玩家明确否决“回合制/三拍逐步结算”，因为会重新变成数学解题。原 v0.5E.1 3×3 累计热量、每拍换位/加热的研发规则先保持不动，新机制先在独立实验页验证。

核心假设：**开火前选择食材与下料顺序（构筑）→ 开火后自动连续实时烹饪（约 12.5 秒）→ 玩家任意时间颠勺或搅拌一次（非强制、非精准 QTE）→ 风味与经营取向不同 → 保存工艺尝试下一锅。**

## 本版可玩范围
- 原型保留现有 8 食材、12 菜谱的配方身份；可选 2–3 种食材与爆炒、焖煮技法。
- 三阶段：爆香/主烹/收味（炖煮时名称为起香/慢炖/调味）；允许部分阶段空置以及一个阶段放多种食材。阶段是连续的入锅时间窗口，**不是回合**，不会等玩家点击“下一拍”才推进。
- Canvas 锅体与食材不断移动；阶段推进时自动投料，有持续的香气提示/视觉反应。
- 实时输入：按键“颠勺”“搅拌”，或在锅面向上滑动/画圈手势。一次烹饪只作**一次**关键操作，允许完全不操作自然出锅；没有窄判定窗、没有按拍次结算、没有失误即失败。
- 三种方向：颠勺偏锅气/焦香与可能的出餐效率；搅拌偏浓鲜融合与品质；自然烹饪偏稳健。烹饪阶段、顺序及食材决定结果提示。
- 结果显示既有菜谱名称（组合匹配时）、特色标签、实验品质和**仅供预览**的经营/员工餐取向。
- 新工艺保存在独立 localStorage 键 `oddpot-cooking-lab-v06`；**不读写主游戏** `oddpot-prototype-v04` 的库存、菜谱、订单、员工、金币或存档。

## 下一轮玩家试玩重点
1. 12.5 秒连续过程是否节奏太慢？玩家在操作后是否陷入被动等待？
2. 颠勺/搅拌有没有触感和视觉奖励？哪个操作更想再次使用？
3. 换食材入锅顺序是否能让玩家产生下一次实验的想法？
4. 工艺的“锅气/融合/家常”差异是否清楚，还是仅仅换了一组数值？
5. 需要一次自由临场更改下料的机会吗？**如果加入，也必须是实时操作，不得退化为暂停三回合。**
