## 问题与范围
营业突发事件卡原本居中却未限制高度，纸色覆盖后正文仍是浅色；野外奇遇的父级 action-forest 有 touch-action:none，短屏滚动可能被祖先阻断。两类真实决策统一为可滚动的纸面事件卡，保留Hearthcraft色系与全部原选项、价格、说明；44px触控，320×568及更短视口可阅读并触达最后一个按钮。弹出期间清理移动按键，不让键盘在事件、暂停或打烊时积累移动输入。原探索摇杆和双指技能、原HUD/账本入口及既有抽屉行为保留；不新增全屏遮罩或禁止原入口，不将事件 Escape 当作免费取消。
## 实装
CSS限定真实事件与场景，仅奇遇存在时将 action-forest touch-action 放开为 pan-y，事件卡内部滚动，普通战斗手势不变；营业事件遮罩允许纵滚、卡片限制高度并增强文字对比。app.js 仅调整输入门槛、面板滚动位置（同一个事件且重绘时保持），不改变任一选择处理函数、事件生成、暂停/时间、金币、规则或存档。现有2D/3D和云港、Z2d2镜头不变。
## 验收
