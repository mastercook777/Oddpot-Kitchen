# CB2-R2a · 烤串工作台动作第一切片
2026-11-27；基线 main ca7fdfa，PR #155 实际 20/20 Actions 通过并已合并。依据 COOKING_MENU_BUILD_V2_GDD §13.4、§13.8、§14.6，玩家授权继续推进。P1 仍待手机体验，不阻止独立表现切片。
## 目标与范围
独立工坊的烤架首先解决食材瞬间出现、整串瞬移、翻面无抬升、签轴偏离食材中心的问题。空签保持可见；穿串从备料侧沿轴平滑进入目标位，先前食材随串槽位平滑调整；整串移火区抬起、平移、放下；自动翻面跟随现有模拟时钟及翻面节拍，短抬升并旋转，不恢复手动翻面必做规则。刷酱沿串移动，烟熏沿串出烟。真实投料与火区选择即时生效，动画不得暂停或影响品质、熟度、时钟、库存。已有正式研发、旧档、配方、经济、词缀不改；其他三厨具逐步打磨、完整收藏/工作台及R3联合验收后置。
## 实现约束
仅对 cbTiming 工坊视觉启用；帧间插值基于观察到的真实串和 lane 状态，不生成额外食材，视觉时钟限制大跳跃，切换 cook 对象清空缓存。签轴与食材几何中心对齐；可选技法继续读真实动作。3D失效保留既有2D状态，完整2D动作升级后置。删除仅工坊重复限帧，不改变正式帧率。缓存键刷新工作台及新模块依赖。
## 验收
纯呈现函数：空签、逐次加入、快速连续加入、火区选择、自动翻面、对象重置、时间回退、大帧差；不修改输入/引擎。旧Y4b和CB2测试、三手机Chrome工作台实际流程、四厨具回归、断网回退、截图；真实玩家观感与帧率必须另验。未通过CI不得合并候选；不宣称整个R2完成。

## 玩家追加范围（本轮）
四厨具动作及特效全面打磨、烤串完整动作、食材颜色/蒸汽/油光/汤汁传递状态、重新设计工作台摆脱菜单感。按四厨具分别推进：WOK 静置/投料落下/翻炒与抛物线颠勺/油光；POT 液面收汁、气泡和搅动；GRILL 空签、穿串、抬升平移、自动翻面、刷酱、熏香；STEAM 开盖、聚汽、排汽。统一场景优先布局：上方紧凑HUD、中间真实厨具、底部食材托盘及情境动作，明确未投/已投、热状态和起锅。动作即时，所有视觉不参与规则；保持旧测试定位器和真实输入。先实现可回归的程序化表现，不承诺新正式模型、真实音效或真机60fps；完整结果/收藏重构仍在R3。若CI尚未确认，提交候选PR而不合入main。
