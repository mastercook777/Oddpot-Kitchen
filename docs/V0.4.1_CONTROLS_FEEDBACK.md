# 《怪味食堂》v0.4.1 — 触控、战斗动画和像素角色

实现日期：2026-10-10 · 玩家反馈修正版 · **需要真实 iPhone Safari 验收**

## 保持不变

- v0.4 探索实体碰撞、自动攻击、锅铲技能、采集、风险、背包撤离结算不做重新设计。
- 原三日菜单经营、料理研发、库存账本、经营事件真实修改因果的规则仍然沿用。
- 目前的 emoji 食材/菜谱信息图标允许继续存在；游戏世界中的主要人物与敌人改为原创像素绘制，不依赖外部图包。

## A · 浮动虚拟摇杆

- 在森林场景任意可触摸位置按下即生成摇杆，原点为按下位置；拖动改变方向与移动力度，松开立即停止并隐藏。
- 9 px 触控死区、54 px 满幅半径、最大方向长度 1；不再需要瞄准左下角固定摇杆。
- 摇杆捕获自己的 pointerId，不抢第二根手指的主动锅铲按钮。
- 不允许接管野外事件选项、HUD、其他交互控件；切阶段/取消触摸/失焦重置移动；键盘 WASD/方向键仍支持。
- 输入数值在 `src/controls_v041.js` 独立纯函数封装和单测。

## B · 可读战斗反馈

- 正常自动攻击真正命中时生成有明确朝向的 `attackFx`；绘制挥铲动作和弧线，目标产生受击闪烁、数字与短暂命中火花。
- 主动锅铲命中产生独立更大的冲击环；被怪物攻击主厨进入 `hurtFx` 闪烁状态。
- 以上效果的触发读取同一套 `stepActionField` 战斗结算，不凭动画额外扣血/掉落。
- 战斗视觉状态可在触控暂停/场景重绘后复原，不另建经济事件。

## C · 像素角色与经营反馈

- `src/pixels_v041.js` 提供可编辑、使用纯 `fillRect` 的 16×24（近似）像素人物，主厨、家庭、冒险者、普通食客、评论家和两类食材怪共享统一描边/色板/比例。
- 支持行走摆腿、挥铲与受击亮灭；不需要任何版权美术或图片文件。
- 森林和餐厅共用同一主厨外形，顾客在餐厅中显示与其客群对应的像素轮廓。
- 波间经营方案执行后，场景显示具体效果，例如“炒锅加速 -3 秒”或“下一波新上架：某菜”；提示来自 `chooseServiceEvent` / `swapBreakMenu` / `breakPrep` 实际规则结果。

## 验收重点

1. iPhone 左右手/不同按下位置能否单手控制？同时点技能是否顺畅？
2. 自动近战出手与敌人受击是否足够清楚？挥铲方向是否对应目标？
3. 像素小人是否比简笔色块更适合游戏氛围，尺寸是否足够？
4. 经营事件的效果是否能明显从餐厅场景和日报看出来？这版未改变事件数量与经济平衡。

## 验证与局限

- Node 全部规则与新增 v0.4.1 回归测试运行通过。
- 独立 HTML Chromium 浏览器烟测，三种 viewport（390×844 / 375×667 / 320×568）无全页滚动和 JS 错误。
- 浏览器模拟不代表真实 iPhone Safari 的触控精度、帧率和硬件性能；正式验收依赖用户真机。
- 原型像素人尚非正式动画素材，仅用程序绘制的多状态角色。正式美术替换时不必修改玩法状态机。
