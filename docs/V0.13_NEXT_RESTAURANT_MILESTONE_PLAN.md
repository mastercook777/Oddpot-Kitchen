# 《怪味食堂》v0.13 下一阶段经营里程碑建议：第二星章 → 真正第三厨位 → 团队经营 → 满星传送门

**2026-10-15；状态：下一阶段开发建议，非当前已开发功能。** 来源：[首星与章节总框架](V0.12A_FIRST_STAR_SPEC.md)、[经营成长方向决策](V0.12_RESTAURANT_GROWTH_DIRECTION.md)、[首星口碑/第四桌量化回归](V0.12E_STAR_QUEUE_PROMOTION_SPEC.md)、[v0.12-F等位表现/目标修复](V0.12F_QUEUE_CHAT_AND_TARGET_FIX.md)及玩家最新反馈。用户已确认第四桌的实际压力和挑战感已经出现，因此不应再一味扩大客流，应开始增加可操作的缓压方式。

## 最重要的设计判断
**从「缺少顾客」转为「如何把真实高峰经营好」**。现阶段两口锅、两名员工、四张桌、每晚有更集中的口碑客流。此前受控80组真实服务模拟，三桌升级到四桌后已更少流失且更多成交，但已存在明显待制作/等待压力。第三炉是中央场景里的封印炉台，当前不具备真实队列/生产；开发时必须把它变成有走位、产出、员工分工和经济影响的真工作站，不能仅显示「第三厨位+20%效率」。

## 建议开发顺序

### 0. v0.12-F · 验收当前两项修复（已在PR #58开发）
- 门口真实等位顾客的低频短对白、紧张但可爱的末期催促，无虚拟顾客和经营属性修改。
- 玩家指定的食材成为本次run冻结的唯一当日目标；分段路线的蘑菇等资源只是当前区段采集通行要求，不得报「今日蘑菇目标完成」。
- 以玩家iPhone实际可读性和多段探险不误报作为客观验证；本次不改第三星/战斗/经济。

### 1. v0.13-A · 第二枚「万味星章」：主题经营挑战（**最高优先级**）
**意图**：给高峰服务压力一个明确的阶段性胜利，而不是继续重复单夜评分。
- 通过第一星且至少进行若干次正常营业后才可在备餐阶段**主动报名**第二星主题评鉴。
- 优先设计两场不同主题、跨两夜的经营考核：
  ①「高峰接待」：排队、入座、等候流失/有效成交、订单及时完成；
  ②「料理与团队」：实际订单满意、菜品多样性和员工技能/备菜配合。
- 仍沿用`serviceDayPlan`、真实座位/订单/桌上评价、`report`及唯一金币流水；失败仅本场复试，不回退已有一星、员工或厨房资产。
- 关键：评鉴指标用真实`queue.peak / abandoned`、`served/totalOrders`、满意/料理工艺；普通经营仍可自由接待，**禁止硬性要求玩家每晚必须排队、雇佣指定员工或靠稀有随机材料才能过关**。
- 通过标准在250+固定种子、低库存/三四桌/员工Lv1–3/不同菜单和人力操作模型实测之后定，不先写拍脑袋的80%上菜率（当前四桌基线约10.14/15.61的成交，且操控与备料各异）。
- **有真实可玩奖励**：第二星章解锁中央封印厨位的**购买资格**，同时解锁一类专门挑战高峰的顾客或评价线索。不能只发「以后可建」空头许可：要与下阶段第三厨位可购买、能实际开工一起对玩家发布。

### 2. v0.13-B · 第三厨位真正实装：空间、产能和操作取舍（与A组成同一可玩里程碑）
- 中央已存在封印炉台位置`DINER_FLOOR.reservedStove` → 真实工作站及碰撞/交互；原左右物理厨位WOK/POT兼容老档，新中央工位应有独立ID，类型可配置炒锅或炖锅。
- 真正生产逻辑：现有`v.stations`的两个队列扩为三站，订单分流与备用锅位配置真实生效；烹饪倒计时、工位升级/食材消费/订单完成同一单据，不能重复出餐。
- 主厨/阿火分工是选择：可以把员工从左右厨位调去中间炉台，也可以由玩家自己在中间操作；**只有人力覆盖时才有真实额外产能**。禁止购买后无操作就永久增加全部菜肴速度。
- 若测试证明1厨+1帮厨无法有效利用3个工作站，应同版解锁第二名帮厨/临时高峰岗位的招聘入口（不能让玩家花钱买彻底没用的炉台），薪资、XP、养成、像素Lv1–3和员工餐沿用现有系统。
- 四桌→三厨位后的服务上限应在控制变量的对照模拟里清晰提升，但不能无限免费堆利润；有真实置装费用、日薪/员工餐成本与背包食材压力。
- 先做单独可玩切片验物理走位、菜单覆盖、工位角色、离线保存，再合并A/B到同一可体验里程碑；完成前第二星的「已解锁新炉」不能向玩家作未实现承诺。

### 3. v0.13-C · 第三星章「满星夜」与第一章收束
- 采用真正不同的考核机制：主题菜谱组合、三波排队压力、门外服务和厨艺对手演出组成一次特殊营业，不是更高固定分数。
- 把研发新料理→探索定向材料→员工升级和备餐→高峰服务串回三系统；评价结果给具体决策反馈。
- 满星后解锁章节传送门的资格，但在**下一世界具备最小可玩闭环**前不做可点击的假门户。

### 4. v0.14 · 第一扇异界传送门：完整独立章节
- 首次跨界至少同时提供：新地貌/怪群+可带回新食材、相应菜谱/Build变化、独有客群与经营评价、新星章目标/新奖励；
- 同一顾客/食材/消费/工艺账本，不另开平行经济；原店、员工和已得到的星级成长可保存并复用。
- 先做一处30–45分钟的真实循环切片评估内容制作成本，避免只画新地图和贴新客皮肤。

## 提议的下一轮验收决策与数量门槛
1. **下一次真正开发**优先立项`v0.13-A/B 第二星评鉴与第三厨位`，同时将第三厨位拆成一轮「真实生产与走位」技术切片。具体星级评分、购买价格、追加员工工资先用新回归工具定，不偷换当前用户已认可的四桌难度。
2. 现有`v0.12-E`基准追踪每晚真实订单数、实际收入/利润、门外流失、厨房实际完成单数；对于第三厨位评估至少80–250相同固定种子的两站vs三站、三种备菜方式、餐饮质量、人力等级、店铺阶段。目标是**既能改善排队/出餐又保留有挑战的经营取舍**。
3. 小屏体验：中央厨位不遮主厨活动路线/阿火移动、不挤占四桌及每个交互区；员工列表/工位配置必须适应320×568，不能引入一排新的永久浮动按钮。
4. 存档：`schema4`迁移、已开始当晚营业冻结旧2站、原先存档首星/四桌/XP/库存不丢；金钱重复出入必须有单次ledger事务与CI回归。
5. 用户试玩关注：第二星目标是否清楚、第三炉需要配置才有价值是否好懂、四桌等位压力是否仍能看见、第三人招聘和加薪是否能带来有意义的回收周期。

## 不建议现在做
- 继续单纯增加默认客流、更多桌子、或强制更高餐馆评分；会让刚形成的挑战变成数值惩罚。
- 提前同时制作多个传送门世界或引入另一套经济，容易削弱餐馆×研发×探索的主循环。
- 立即改探索掉落经济：玩家反馈探索内容/经济基本成立，本轮仅修目标误报。

## 2026-10-15 用户再次决策后的正式顺序修订
- **已明确修订旧A/B顺序**：不可先单独推出第三厨位而没有新员工。v0.13-A 先做可完整试玩的「第三真实工位＋第二帮厨」一键扩编（[PR #59](https://github.com/mastercook777/Oddpot-Kitchen/pull/59)已合并，v0.13.0-alpha.1），需要第一星、第四桌及真实金币。与旧稿「第二星后才解锁中央厨位」有冲突：**以这条2026-10-15玩家新确认的安排为准**。在二星之前先让玩家拥有处理当前高峰的主动手段，随后二星再考验经营、研发与库存策略。
- **随后v0.13-B**：第二星章两阶段经营评鉴（压测实际排队、利润、质量与菜单策略），奖励不能再是「首次解锁已开放的第三厨位」；可考虑解锁烤架可购/研发资格或新服务、扩编晋升上限，但需先验证可实际兑现。
- **v0.13-C烤架与烤叉切片**：不把烤架塞进A以免同时拓展第三种武器与几百种自动食材组合。先做双面火候操作、3—6道手工料理、独特穿刺武器和小范围平衡切片，再扩展。
- **后续水吧/甜品**：水吧作为前厅等位服务/饮品增益，不必对应战斗武器。甜品须先有可预期的甜味基础材料（当前只有稀有星露花蜜和洋葱甜香，无法承载完整稳定甜品供应）；保留下一章节候选。
- 不因第三工位上线再无条件增加顾客；店员+工位必须是真订单处理、真实薪资与成长，菜单高度匹配时才收益更大。80同客源真模拟：混合菜单成功上菜10.16→10.94、利润95.39→96.50；纯炒锅套餐上菜10.06→12.89、利润77.36→105.03；低库存时可能因额外12工资导致利润下降。玩家应可在备餐界面选择让小炭休息，避免为低需求白发工资。
