# v0.15-D · 云港经营与双店联动修整规格

**2026-10-20 · 先行设计，功能代码尚未实施。** 基线为 `v0.15.0-alpha.3`。依据[首门审计](V0.15C_CLOUD_HARBOR_REWORK_SPEC.md)后的源码核查与玩家本轮三项明确反馈：蒸笼封笼／排汽要各自影响评分；新材料菜谱不足；旧店运输应提供云港缺少的旧世界食材，云港生态主要供应当地食材。本规格取代 v0.15-C 固定兑换云谷米／浮苔叶的补给内容，不回滚其真实营业、每日上限、唯一账本约束。

## 玩家路径与经济边界

1. 云港首日只靠当地市场、云港采集和初始少量鸡肉／洋葱，也能研发至少三道两厨具可覆盖的本地菜并真实营业；不回旧店也可获当地首星。每日新生成市场只卖四种当地常材，各有真实库存/价格。既有云港当日旧市场报价与已购数量原样保留到次日，不追扣或重补。
2. 云港两个生态只产当地普通食材，风蛾掉浮苔，风暴首领给唯一晶核；移除新探索中的鸡怪、野外洋葱与森林商人/蘑菇奇遇。当地商人与旅人只交换本地普通材料，不能绕过首领或带出不在当地菜单里的旧世界稀有材料。旧在途探索继续使用冻结地图与事件。
3. 原店真实营业当日至少一单才得一委托；云港每当地日最多用一张。兑换从三种**旧世界普通食材包**中择一：`鸡肉×3、洋葱×2`；`蘑菇×3、蒜瓣×2`；`土豆×2、火椒×2`。无旧店金币转移、无新食材、无稀有 Boss 材料。券余额是跨章资产，账本仍以当前云港日为唯一键。已领取过旧固定补给的当地日不得再次领，新版不追溯重发。
4. 首次入港可继承一类旧厨具 Lv2；此后旧店的 WOK/POT 熟练 Lv2 允许云港以当地金币选择折价培训（WOK 45、POT 55；常规 60/75），只影响尚未升到 Lv2 的云港厨具，不复制员工或已开始的营业快照。云港蒸笼为独立本地厨具，可在购入后花 80 当地金币升 Lv2，每单 -2 秒；没有蒸笼探索武器。

## 菜谱与蒸法

- 保留现有八道云港菜、旧菜仅图鉴与至少一当地食材的上架边界。新增至少六道**纯当地常材**菜，覆盖炒锅与炖锅，首日米、浮苔、蛋与可购酸铃能组成三道以上菜单；另至少四道当地＋旧店委托食材的精选菜，分别消耗菌/蒜/薯/椒等，避免整包无用。每道都是手工登记在索引中的 2–3 材料配方，不加入旧世界八食材组合池。研发耗料、版本、菜单、预制、真实订单与日报走原链路。
- 蒸制时 `封笼` 必须在两料均入笼后及时执行才给品质 +5，`排汽` 必须在封笼后合理时间窗、两料仍在笼中执行才再给 +7；过早排汽有真实扣分。火候仍可失败，动作不能无条件保底。两动作都需要在操作复盘逐项标明触发条件、实际加减分；成熟度的封闭蒸汽从动作时间开始计算，排汽后不再当作密封，不预支未来操作的加热收益。无动作可售基础品质与动作正确、早排汽三种同原料对照必须有可解释差异。其他锅具评分不改。
- 蒸菜的标签、客群偏好和店内价值应与同食材炖菜有区别；对同种子真实订单与厨位占用做对照，不声称基础标价差就是已实现利润。

## 云港 UI、NPC 与成长

- 野外分支/奖励预告指向风暴首领与风暴晶核；市场页只描述当前真实可购品类和四个报价。蒸笼可安装任意真实厨位，成长页显示购买、Lv2、每单节时，不提不存在的蒸笼武器。
- 云织旅人和搬运客有当地身份、口味及等位/点单短句；本地宣传只引入实际云港客，成本在真实营业扣除并可在日报追溯。少量既有旅客仍可自然来港，但不把森林公会当云港宣传渠道。
- 当地首星后应增加可验证的自然客流，使第四桌、第三厨位的投资有真实订单空间；同种子充分供料/缺料下分别测利润和排队。未开放的云港二星/下一门明确写未开放。图鉴共享知识但能看本章可营业菜和当前章顾客，本地进度不使用全局菜谱总数冒充。

## 回归与迁移

- 新档、原店两星/三星旧档、已进云港的 alpha.1/alpha.3 旧档、在途野外及已开始营业快照；旧已购市场、旧委托券、已兑换日、旧菜、旧员工不重复扣发。每章库存/金币/员工/经验/星章独立，订单/探索/委托账本唯一。
- 批量种子检查云港探索节点、敌群、奇遇实际交易均无森林专属材料；只云港路径可开业，本地首星可达；三类委托各真实可用且日上限一致；蒸笼两动作、早排汽、升级与读档一致。
- 320/375/390px 浏览器走传送门、探索、当地 NPC、研发、菜单、双厨位、委托、日结；离线单文件与静态 Pages 入口。iPhone/Android 主观触控、中文和节奏单列玩家验收。真实多日供需记录只作调参依据，不把静态地图潜力误称战斗净收益。

三类委托包的相对价值、折价培训成本、蒸笼购入和升级回本、当地星章客流提升、两类宣传回本、十余道当地菜的菜单竞争。参数是第一版可审查实现目标，不代表真机已验收。
