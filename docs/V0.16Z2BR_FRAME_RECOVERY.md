# Z2br · 3D 首帧与场景切换稳定性修复
2026-11-25，玩家在 iOS 截图反馈 Z2a3 清晨场景只显示热点和棕色底，前几版均需刷新才正常。当前 main 基线 Z2b。先修稳定性，不扩展玩法、美术或修改存档。
## 代码证据与修复
- 旧主 RAF 在 frame 尾部才安排下一帧；任一未捕获异常（包括等待异步 3D 模块时的 2D 绘制）会永久终止调度。此漏洞可解释“3D预览待命但画面空白”，尚未确认用户真机具体抛错。
- 每次 frame 先安排唯一下一帧，再执行原规则；各场景绘制独立容错、同一异常只记录一次，正常帧清除诊断。场景离开清理对应诊断。Canvas 2D context 暂不可用或丢失时不调用方法。错误显示进入恢复中，保留原 Y6a 3D 重建与手动重试机制。
- index 标识 Z2br 和 app/scenes 缓存键；同步离线 HTML 的相同代码，仍为离线 2D。无经济、订单、库存、存档格式或渲染模式默认值变动。
