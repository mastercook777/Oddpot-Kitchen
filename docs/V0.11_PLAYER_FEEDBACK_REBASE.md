# 《怪味食堂》v0.11 体验重估 · 2026-10-13 玩家实机反馈

**状态**：方向调整记录 / 玩法扩展待开发 / 低可遇见率的修复属于当前可直接实施的缺陷。现行基础 v0.11.0-alpha.1。
**触发反馈**：两大地图各通关三张小图，均未见奇遇；地形辨识改善，但场景绘制精度、怪物数量及种类、地图丰富度仍不构成「探索系统 2.0」。

## 1. 代码审计（事实）

- 地图：`generateBiomeMap` 为 9×11 世界；变种只是少量资源/障碍的种子交换。没有镜头跟随、真实子区空间结构差异。
- 怪：`startActionField` 每段最多四个普通怪（基数 1–3 + 波动与风险修正）。已有鸡、野猪、孢子怪、蒸汽蟹、火椒怪和两名 Boss，但具体子生态混合稀疏；画面/行为差异仍不足。
- 奇遇缺席原因：旧 `sourceCount>=4 && seed%5===0` **按单段**附加事件，`count` 为 2/3 的子区没有机会；随机有事件还需靠近坐标才触发。设计中的每三段出现率与轻保底尚未实现。当前 UI/交易仍只有一位旧「流浪调味师」，不是 v0.11-B 商人与专供材料。
- 绘制：Canvas 仍主要是几何背景与有限程序像素角色；资源/危险区分有改善，但缺少多层次结构、远近场景、情境演出和更多地形物件。

## 2. 重定义 2.0 的验收：不是地图换肤

| 维度 | 可感知目标 | 工程方案（候选，不视为已交付） |
| --- | --- | --- |
| 空间 | 两个大区、八生态走法真正不同；一段路有明显近景/绕路/捷径 | 改成 **镜头追随的扩展地图**，候选世界 12×16 单位，手机仍显示约 9×11 视野；逻辑障碍、资源、装饰同源，不卡路线 |
| 绘制 | 草甸、菌沼、古树、菜圃、热泉、蒸汽、赤焰、晶池无需阅读名字就能认出 | 提高**角色/怪物/资源/地标的独立轮廓与像素细节**；前/中/后景层次和生态专属动效，拒绝纯同色圆点铺陈 |
| 生物 | 每区有不同猎物、行为与遭遇节奏，不是光把怪从 1 提到 4 | 扩展生态原生怪，区分冲锋、远程、守卫、干扰型；安全区 2–4，风险区 4–7 **为测试目标**；明确背包/补货主导，不加无意义清怪门槛 |
| 奇遇 | 每次完整探索有值得走近的互动，商人/旅人/环境事件可识别 | 一次性事件身份、可见召唤点、路线提示、稳定 seed、真野外包与金币结算；之后加入 **逆潮酸浆 / 星露花蜜及 4 料理** |
| 经营衔接 | 稀有发现导致新菜谱、真实限量经营，而不是怪掉更高战力 | 只进入现有研发、工艺快照、隐藏菜单、真实订单/收入引擎 |

## 3. 实施节奏和不偷换「已实现」

### v0.11-B0 · 奇遇可遇见性热修（本轮动手）

- 暂时采用 **每次完成三段 run 至少生成一次可主动发现的旧旅人奇遇**，安排在第 2/3 段、接近真实通往目标的可通行路径；仍要求玩家自行走近，不弹窗强制购买。
- 同 run **最多一位**，节点标识稳定、刷新/读档/跨段不可重复出现，拒绝后不再拿奖。无钱/满包问题仍按旧事件处理；不假装已经有专供材料。
- 玩家已经进入探索中的旧存档维持既有地图，下一次完整 run 使用新事件计划；不重抽已生成内容。
- 在 PR 中添加大区、多个 seed、两/三段，节点位置与历史兼容回归。**短期 100% 可生成，是为验证发现操作而设置的节奏补丁，不是最终 35–50% 稀有商人概率**。新商人仍必须稀有，未来生态事件可相对常见。

### v0.11-B1 · 地图视觉和镜头（尚未开发）
- 先实现视野与镜头，把地图从 9×11 直接整体缩放导致像素更小的问题解决；再做真实地形轮廓、障碍路径、纹理、交互层和大/小屏。
- 每个生态至少两个结构模板及多种安全通路；基础资源必须有稳定采集补货路径。

### v0.11-B2 · 生态怪群和战斗节奏（尚未开发）
- 怪物行为/画面成组升级，保留自动普攻、WOK/POT 操作差异；不能仅靠增加 HP 或敌人堆叠冒充内容。
- 分别记录地图行进时间、真实受伤、拾取量、背包丢弃率，不拉长每日循环。

### v0.11-C · 完整一次性商人/旅人/生态奇遇与料理联动（尚未开发）
- 恢复 [原 v0.11-B/C 经济契约](V0.11_EXPLORATION_2_0.md)；金币付款一次、物资交换原子、离店结算一次；新稀有食材、四道精选料理和隐藏菜单均独立实装测试。
- 商人/旅人/生态各自有视觉、文案、报酬/成本、存档判定；**当前旧调味师临时提升出现率不算该功能完成**。

## 4. 验收与保底

1. 森林和热泉各完成 3 段，节点在第 2/3 段真实可走到；至少能主动发现一次；跳过不强制互动（玩家可能仍主动避开）。
2. 至少 64 seeds × 2 地区验证：只有一份旧奇遇节点、路径可达、不压到目标、障碍、陷阱或出生点；同种子重载地图和交互一致。
3. 保存兼容 `oddpot-prototype-v04` / schema `4`，老正在探索的状态不改变、不重新生成金币/包物。
4. CI `npm test`、`npm run build`、离线版构建后才可合并；iPhone 视觉/手感另验收。

## 5. 重要认知

v0.11.0-alpha.1 是 **地图可读性打底**，不是玩家认可的「探索系统 2.0」。更新版目标应按「空间与镜头、生态怪群、奇遇与独特料理」完整验收，不能用 CI 绿灯代替体验评价。
