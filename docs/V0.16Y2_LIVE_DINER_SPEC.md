# v0.16-Y.2a · 真实餐厅 3D 接入
2026-11-24 · 用户认可 Y 方向继续落地，基线 Y.1 PR #101 / 930f263。目标不再做另一个假经营实验，而是正式游戏可选 3D 表现。
## 范围
正式在线入口 ?render=3d 可选启用，默认 2D、旧离线包不变；边境 forecast 与 walkable service，云港、非 walkable、研发/探索原样。Three.js 固定 0.170.0 异步 CDN，失败/上下文丢失自动退回 2D。状态唯一来源原 game，禁止独立计时、库存、生产、自动订单。真实 dinerFloor 桌位2/3/4、炉位2/3及 WOK/POT/GRILL/STEAM、真实主厨/顾客/雇员、传菜/工作/等待/评价、原来的菜单和操作。优先保持 UI 和规则。原演员计算从 drawRestaurantV075 抽出同源函数，2D 使用同函数；3D 使用只读快照，角色方向与位置由原演员输出。保留原 2D 操作输入（屏幕摇杆映射到 x/y），采用正向斜俯视相机，避免旋转造成走位方向不一致。状态与渲染无反向写入；DOM 每秒重建时复用 WebGL 资源，离开场景隐藏；切换/错误回退不影响订单。
## 验收
测试同源 actor/家具数据、3D 可选性、旧 2D/离线无新外部依赖、两世界隔离、真实菜盘和订单状态标记；320/375/390、营业摇杆/技能/暂停/出餐/日终；实际 WebGL 与手机 FPS 待核。首轮仅 3D 表现切片，未替代正式美术、未全面迁移旧 UI；后续 Y2b 优化各角色种族/动作/反馈与空间交互，Y3 森林。若 CDN/设备失败仍可完整游玩旧 2D。
