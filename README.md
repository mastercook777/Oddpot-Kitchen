# 怪味食堂 · Oddpot Kitchen H5 v0.4.1

**状态：原型开发版本，玩法未通过玩家真机验收。**

试玩入口（须 GitHub Pages 部署后）：https://mastercook777.github.io/Oddpot-Kitchen/

## 本轮开发范围

- **A 森林探索**：固定场景实时连续移动，单摇杆，近距离自动攻击，两种敌人，锅铲击退，靠近自动采集，三种野外事件选择，背包/撤离交易结算。
- **B 经营事件**：新客入店才点单，波次间事件选择 / 菜单换菜 / 备餐三选一，成本与后续订单、产能、反馈直接联动。
- **C 原型简绘**：Canvas 绘制森林/顾客/厨具/餐厅，场景持续更新；不依赖正式美术资源，手机固定 viewport。

料理研发保留 8 种食材、12 道菜和 3×3 / 三拍火候实验。原版 GDD v0.2 锁定的精简内容仍由 v0.2 基线版本保留，不应把 v0.4.1 额外资源混入原 MVP 规格。

## 操作

1. 看今日客群预测，选择森林目标与路线。左下摇杆移动，靠近植物自动采集，靠近敌人自动攻击；点“锅铲击退”使用主动技能；可以随时撤离。
2. 在 3×3 炒锅按三拍实验新菜，或直接去安排菜单。
3. 上架 3 道菜，按需备餐，开始营业。
4. 每波休整可以选**经营事件 / 临时换菜 / 应急备餐**之一。最后查看报表中的“店长今日决策”。
5. 第三天踢馆替代普通营业；之后继续轮次。

## 工程

- `src/data.js`：食材、菜谱与顾客定义
- `src/engine.js`：共享资源和结算、做菜、双工位自动营业及事件选择
- `src/field_v04.js`：实时探索动作模拟（不自行入库存）
- `src/scenes_v04.js`：绘制森林及餐厅画面，只有呈现职责
- `src/app.js`：手机界面、触控摇杆、场景事件和 UI
- `tests/*.test.js`：Node 原生引擎回归
- `docs/GDD_v0.4.1_PLAYABLE.md`：变更边界、已实现与未实现清单
- `standalone.html`：单文件、便于离线测试的打包版

原型没有服务器、广告、在线存档或商业素材，使用 localStorage 单设备自动保存。

```bash
npm test
npm install
npm run dev
python scripts/build-standalone.py
```

静态 Pages 直接从仓库 `main` 分支根目录的 `index.html` 提供，**不需要 Vite 构建**。`prototype/v0.3-baseline` 和 `prototype/v0.2-baseline` 用作玩法对照。
